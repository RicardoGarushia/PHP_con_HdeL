# 17. ESTRUCTURA DE CONTROL FOREACH

La estructura de control **`foreach`** provee un modo fácil y directo para iterar sobre arreglos y objetos en PHP. Su propósito principal es recorrer cada elemento de una colección de datos de manera secuencial sin necesidad de gestionar manualmente un contador o índice.

---

## 17.1. Definición y Sintaxis Base

**`foreach`** opera únicamente en arreglos u objetos. Intenta ejecutarlo en una variable con un tipo de dato diferente o no inicializada provocará un error de tipo.

Existen dos sintaxis principales según la información que se requiera extraer en cada iteración:

### 17.1.1 Sintaxis Solo Valor

Útil cuando únicamente se necesita manipular el contenido de cada elemento.

```php
foreach ($arreglo as $valor) {
    // Código a ejecutar para cada valor
}
```

### 17.1.2 Sintaxis Clave => Valor

Indispensable para arreglos asociativos o cuando se requiere conocer la posición/índice numérico dentro de un arreglo indexado.

```php
foreach ($arreglo as $clave => $valor) {
    // Código a ejecutar con acceso a la clave ($clave) y al valor ($valor)
}
```

---

## 17.2. Casos de Uso Prácticos

### 17.2.1. Recorrer un Arreglo Indexado (Solo Valor)

Itera elemento por elemento asignando el valor a la variable declarada después de as.

```php
// Definición de un array indexado
$nombres = ["Arturo", "Beatriz", "Carlos", "Daniela", "Efrén"];

foreach ($nombres as $nombre) {
    echo "Nombre: $nombre\n";
}
```

### 17.2.2. Recorrer un Arreglo Asociativo (Clave y Valor)

Permite acceder de forma limpia tanto a la clave (key) como al valor asociado (value).

```php
// Definición de un array asociativo
$persona = [
    "Nombre" => "Ricardo",
    "Apellido Paterno" => "García",
    "Apellido Materno" => "López",
    "Edad" => 34
];

foreach ($persona as $clave => $valor) {
    echo "$clave: $valor\n";
}
```

### 17.2.3. Extracción de Índices Numéricos en Arreglos Indexados

Aunque un arreglo sea indexado, la sintaxis $clave => $valor expone el índice numérico interno (0, 1, 2...).

```php
// Obtención del índice exacto
foreach ($nombres as $indice => $valor) {
    echo "Índice: $indice, Valor: $valor\n";
}

// Formateo para enumeración legible (base 1)
foreach ($nombres as $indice => $valor) {
    $numero = $indice + 1;
    echo "Nombre $numero: $valor\n";
}
```
