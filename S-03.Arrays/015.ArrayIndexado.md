# 15. ARRAYS: Parte 1. Array Indexado

Un **array** es una estructura de datos fundamental que permite almacenar múltiples valores dentro de una sola variable, organizados en posiciones consecutivas.

---

## 15.1. Definición y Clasificación de Arrays en PHP

Aunque internamente PHP implementa todos los arrays como un mapa ordenado (_ordered map_), conceptualmente se clasifican en cuatro categorías según el modo en que se identifican e interconectan sus elementos:

1. **Array Indexado:** Los elementos se identifican mediante un índice numérico entero consecutivo (comenzando desde `0`).
2. **Array Asociativo:** Los elementos se identifican mediante claves explícitas personalizadas de tipo `string`.
3. **Array Indexado Multidimensional:** Un array que contiene uno o más arrays como elementos internos.
4. **Array Asociativo Multidimensional:** Un array multidimensional estructurado mediante claves personalizadas de tipo `string`.

---

## 15.2. Arrays Indexados

En un **array indexado**, PHP asigna automáticamente un índice numérico entero iniciando en `0` para el primer elemento, incrementándose en `1` de forma secuencial por cada valor agregado.

### 15.2.1 Array Indexado con Sintaxis Tradicional (`array()`)

Es la sintaxis histórica utilizada en versiones de PHP previas a la 5.4. Para agregar nuevos elementos se recurre habitualmente a funciones nativas como `array_push()`.

```php
// Inicialización
$nombres = array("Pedro", "María", "Juan", "Agustín", "Janeth");

echo "El array indexado con sintaxis tradicional contiene PRIMERO los siguientes elementos (uso de \"print_r\"):\n";
print_r($nombres);

// Agregar elementos al final mediante función array_push()
array_push($nombres, "Mónica", "Violeta", "Claudia");

echo "El array indexado con sintaxis tradicional contiene AHORA los siguientes elementos (uso de \"print_r\"):\n";
print_r($nombres);
```

Nota: Aunque la sintaxis tradicional sigue vigentes por compatibilidad con código heredado (legacy), la sintaxis corta es la convención moderna recomendada.

### 15.2.2 Array Indexado con Sintaxis Corta (`[]`)

Introducida en PHP 5.4, permite definir arrays utilizando corchetes [], lo que reduce la verbosidad del código y mejora la legibilidad.

```php
// Inicialización con sintaxis corta
$nombres = ["Pedro", "María", "Juan", "Agustín", "Janeth"];

echo "El array indexado con sintaxis corta contiene PRIMERO los siguientes elementos (uso de \"print_r\"):\n";
print_r($nombres);

// Agregar elementos al final utilizando corchetes vacíos []
$nombres[] = "Mónica";
$nombres[] = "Violeta";
$nombres[] = "Claudia";

echo "El array indexado con sintaxis corta contiene AHORA los siguientes elementos (uso de \"print_r\"):\n";
print_r($nombres);
```

### 15.2.3. Modificación y Sobrescritura por Índice

Si se especifica un número entero dentro de los corchetes [$indice], PHP no agrega un elemento nuevo al final, sino que sobrescribe el valor existente en la posición indicada.

```php
// Sobrescribe el valor existente en los índices 0 a 6
$nombres[0] = "Ricardo";
$nombres[1] = "Ricardo";
$nombres[2] = "Ricardo";
$nombres[3] = "Ricardo";
$nombres[4] = "Ricardo";
$nombres[5] = "Ricardo";
$nombres[6] = "Ricardo";

echo "El array indexado con sintaxis corta contiene FINALMENTE los siguientes elementos (uso de \"print_r\"):\n";
print_r($nombres);
```
