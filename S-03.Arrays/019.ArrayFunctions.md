# 19. ARRAYS: Funciones para Arrays

En PHP, una **función** es un bloque de código reutilizable diseñado para ejecutar una tarea específica. PHP cuenta con un amplio conjunto de funciones nativas creadas para simplificar la manipulación, inspección, búsqueda y transformación de arreglos.

---

## 19.1. Funciones de Inspección y Salida

- **`print_r($array)`:** Muestra información legible sobre una variable o arreglo, exponiendo sus claves e índices junto a sus valores.
- **`count($array)`:** Devuelve el número total de elementos contenidos en un arreglo.

```php
$frutas = ["Manzana", "Naranja", "Pera"];
echo "El arreglo contiene " . count($frutas) . " registros.\n\n"; // Imprime 3
print_r($frutas);
```

---

## 19.2. Manipulación de Elementos (Pila y Cola)

- array_push($array, ...$valores): Agrega uno o más elementos al final del arreglo.

```php
array_push($frutas, "Uva", "Zapote");   // $frutas = ["Manzana", "Naranja", "Pera", "Uva", "Zapote"];
echo "El arreglo contiene " . count($frutas) . " registros.\n\n"; // Imprime 5
print_r($frutas);
```

- array_pop($array): Extrae y elimina el último elemento del arreglo, retornando su valor.

```php
$ultimo = array_pop($frutas);   // $frutas = ["Manzana", "Naranja", "Pera", "Uva"];
echo "El arreglo contiene " . count($frutas) . " registros.\n\n"; // Imprime 4
print_r($frutas);
echo "\n\nEl último valor pop-eado es: $ultimo";
```

- array_unshift($array, ...$valores): Agrega uno o más elementos al inicio del arreglo.

```php
array_unshift($frutas, "Albaricoque", "Cereza");   // $frutas = ["Albaricoque", "Cereza", "Manzana", "Naranja", "Pera", "Uva"];
echo "El arreglo contiene " . count($frutas) . " registros.\n\n"; // Imprime 6
print_r($frutas);
```

- array_shift($array): Extrae y elimina el primer elemento del arreglo, retornando su valor.

```php
$primero = array_shift($frutas); // $frutas = ["Cereza", "Manzana", "Naranja", "Pera", "Uva"];
echo "El arreglo contiene " . count($frutas) . " registros.\n\n"; // Imprime 5
print_r($frutas);
echo "El primer valor shift-eado es: $primero";
```

---

## 19.3. Búsqueda y Verificación

- in_array($busqueda, $array): Comprueba si un valor existe dentro del arreglo. Devuelve true si lo encuentra o false en caso contrario.

```php
if (in_array("Manzana", $frutas)) {
    echo "El valor 'Manzana' está presente en el array de frutas.\n\n";
}
```

- array_key_exists($clave, $array): Verifica si una clave o índice específico existe dentro del arreglo.

```php
$usuario = ["nombre" => "Ricardo", "edad" => 34];

if (in_array("Ricardo", $usuario)) {
    echo "El nombre 'Ricardo' está presente.\n\n";
}

if (array_key_exists("edad", $usuario)) {
    echo "La clave 'edad' existe en el arreglo.\n\n";
}
```

---

## 19.4. Combinación y Modificación

- array_merge($array1, $array2, ...): Combina dos o más arreglos. Si existen claves de tipo string duplicadas, el valor posterior sobrescribirá al anterior; si son índices numéricos, los elementos se reordenan secuencialmente al final.

```php
$backend = ["PHP", "Laravel"];
echo "El arreglo contiene " . count($backend) . " registros.\n\n"; // Imprime 2
print_r($backend);

$frontend = ["HTML", "CSS", "Bootstrap", "JavaScript", "Vue"];
echo "\n\nEl arreglo contiene " . count($frontend) . " registros.\n\n"; // Imprime 5
print_r($frontend);

$fullstack = array_merge($backend, $frontend);
echo "\n\nEl arreglo contiene " . count($fullstack) . " registros.\n\n"; // Imprime 7
print_r($fullstack);
```
