# 16. ARRAYS: Parte 2. Array Asociativo

Un **array asociativo** es una estructura de datos en la que cada elemento se almacena y recupera mediante una clave personalizada (_key_) asociada a un valor (_value_), utilizando el operador de flecha doble (`=>`).

---

## 16.1. Definición y Características

A diferencia de los arrays indexados que utilizan posiciones numéricas consecutivas (`0, 1, 2...`), los arrays asociativos permiten utilizar claves de tipo `string` o `integer` con un significado semántico directo (por ejemplo, `"nombre"`, `"correo"`, `"edad"`).

- **Clave (_Key_):** Identificador único dentro del array. Si se intenta asignar un valor a una clave existente, se sobrescribirá su contenido.
- **Valor (_Value_):** Cualquier tipo de dato en PHP (cadenas, enteros, flotantes, booleanos u otros arrays).

---

## 16.2. Declaración e Inicialización de Array Asociativo con Sintaxis Corta (`[]`)

La sintaxis corta con corchetes `[]` es el estándar moderno para definir un array asociativo relacionando cada clave con su valor mediante `=>`.

```php
// Definición de un array asociativo
$persona = [
    "nombre" => "Ricardo",
    "apellidoP" => "García",
    "apellidoM" => "López",
    "edad" => 34
];

echo "El array asociativo con sintaxis corta contiene PRIMERO los siguientes elementos (uso de \"print_r\"):\n";
print_r($persona);
```

---

## 16.3. Inserción y Modificación de Elementos en Array Asociativo con Sintaxis Corta (`[]`)

### 16.3.1. Inserción de Nuevas Claves

Para incorporar nuevos pares clave-valor después de la inicialización, se especifica la nueva clave entre corchetes:

```php
// Inserción en un array asociativo
$persona["estado"] = "CDMX";
$persona["pais"] = "México";

echo "El array asociativo con sintaxis corta contiene AHORA los siguientes elementos INSERTADOS AL FINAL (uso de \"print_r\"):\n";
print_r($persona);
```

### 16.3.2. Modificación/Sobreescritura de Claves Existentes

Si se asigna un nuevo valor utilizando una clave que ya existe dentro del array, PHP actualiza el valor almacenado en esa posición en lugar de crear un elemento nuevo:

```php
// Sobrescribe el valor de la clave "nombre"
$persona["nombre"] = "Leonardo";

echo "El array asociativo con sintaxis corta contiene FINALMENTE los siguientes elementos SOBREESCRITOS POR CLAVE (uso de \"print_r\"):\n";
print_r($persona);
```
