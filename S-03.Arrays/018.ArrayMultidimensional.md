# 18. ARRAYS: Array Multidimensional

Un **array multidimensional** es un array que contiene uno o más arrays como elementos. Permite estructurar datos en forma de matrices, tablas o colecciones complejas de entidades (como registros obtenidos de una base de datos).

---

## 18.1. Definición y Clasificación

Dentro de las estructuras multidimensionales en PHP se identifican dos variaciones principales:

1. **Array Multidimensional Indexado:** Contiene sub-arrays cuyos elementos se organizan mediante índices numéricos (`0, 1, 2...`).
2. **Array Multidimensional Asociativo:** Contiene sub-arrays cuyos elementos utilizan claves explícitas de tipo `string` (`"nombre"`, `"apellido"`, etc.).

---

## 18.2. Array Multidimensional Indexado

### 18.2.1. Declaración

Los sub-arrays se alojan como elementos dentro del array principal mediante la sintaxis de corchetes `[]`:

```php
$usuariosIndexados = [
    ["Ricardo", "García", "López"],      // Índice 0, subarray 0
    ["María", "González", "Hernández"],  // Índice 1, subarray 1
    ["Juan", "Pérez", "Ramírez"],        // Índice 2, subarray 2
    ["Janeth", "Pérez", "Acosta"]        // Índice 3, subarray 3
];
```

### 18.2.2. Inserción

Para insertar nuevos datos se pueden aplicar dos enfoques:

- Agregar un sub-array entero al final del arreglo principal:

```php
// Se agrega un nuevo registro
$usuariosIndexados[] = ["Carlos", "Mendoza", "Sánchez"];
```

- Agregar un campo individual a un sub-array existente especificando su índice:

```php
// Se agrega un nuevo campo
$usuariosIndexados[0][] = "Licenciatura"; // Se añade al final del sub-array 0
```

### 18.2.3. Modificación

Para modificar un valor existente se asigna el nuevo dato haciendo referencia a la posición exacta mediante sus coordenadas de índice [sub-array][elemento]:

```php
// Se modifica el valor en el elemento 0 del sub-array 0
$usuariosIndexados[0][0] = "Leonardo";
```

### 18.2.4. Acceso Directo por Índices

Para acceder a un elemento específico se utilizan corchetes encadenados: el primer índice selecciona el sub-array y el segundo el elemento interno.

```php
// Accede a "García" (Sub-array 0, Elemento 1)
echo $usuariosIndexados[0][1] . "\n";
```

### 18.2.5. Recorrido mediante `foreach` Anidado

Para iterar todas las posiciones se emplea un primer ciclo `foreach` para recorrer los sub-arrays y un segundo `foreach` para sus elementos individuales:

```php
foreach ($usuariosIndexados as $indiceArray => $subArray) {
    echo "Arreglo $indiceArray: ";
    foreach ($subArray as$valor) {
        echo "$valor ";
    }
    echo "\n";
}
```

## 18.3. Array Multidimensional Asociativo

Es la **estructura estándar para representar tablas de bases de datos o colecciones JSON**. Cada sub-array representa un registro con atributos definidos.

### 18.3.1. Declaración

```php
$usuariosAsociativos = [
    [
        "nombre" => "Ricardo",
        "apellidoPaterno" => "García",
        "apellidoMaterno" => "López"
    ],
    [
        "nombre" => "María",
        "apellidoPaterno" => "González",
        "apellidoMaterno" => "Hernández"
    ]
];
```

### 18.3.2. Inserción

Para insertar nuevos datos se pueden aplicar dos enfoques:

- Agregar un nuevo registro asociativo al final del arreglo principal:

```php
// Se agrega un nuevo registro
$usuariosAsociativos[] = [
    "nombre" => "Carlos",
    "apellidoPaterno" => "Mendoza",
    "apellidoMaterno" => "Sánchez"
];
```

- Agregar un nuevo par clave-valor a un registro existente:

```php
// Se agrega un nuevo campo, o mejor dicho par clave-valor
$usuariosAsociativos[0]["rol"] = "Administrador";
```

### 18.3.3. Modificación

Se sobrescribe el valor accediendo al sub-array mediante su índice numérico y especificando la clave de tipo string correspondiente:

```php
// Se modifica el nombre del sub-array 0
$usuariosAsociativos[0]["nombre"] = "Ricardo Leonardo";
```

### 18.3.4. Acceso Directo

Se combina el índice numérico del sub-array con la clave de tipo string deseada:

```php
// Accede al apellidoPaterno del primer registro: "García"
echo $usuariosAsociativos[0]["apellidoPaterno"] . "\n";
```

### 18.3.5. Recorrido Completo (`foreach` Anidado)

```php
foreach ($usuariosAsociativos as $indice => $persona) {
    echo "Registro $indice:\n";
    foreach ($persona as $clave =>$valor) {
        echo "  $clave:$valor\n";
    }
    echo "\n";
}
```
