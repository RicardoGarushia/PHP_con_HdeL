# 29. POO: Getters y Setters

En la Programación Orientada a Objetos, los **Getters** (métodos accesores) y **Setters** (métodos mutadores) constituyen la interfaz pública que permite leer y modificar las propiedades privadas o protegidas de una clase de forma segura, encapsulada y controlada.

---

## 29.1. ¿Qué son los Getters y Setters?

- **Getter (`get...()`):** Método público cuyo único propósito es **retornar (leer)** el valor de una propiedad sin exponerla directamente.
- **Setter (`set...()`):** Método público diseñado para **asignar o actualizar (escribir)** el valor de una propiedad, aplicando reglas de validación antes de modificar el estado interno del objeto.

---

## 29.2. ¿Por qué usar Getters y Setters en lugar de `public`?

Hacer una propiedad pública (`public`) permite que cualquier código externo le asigne valores inválidos o corruptos. Al privatizar las propiedades y acceder a ellas mediante métodos se obtiene:

1. **Control de Acceso e Inmutabilidad:** Puedes crear propiedades de solo lectura (omitiendo el Setter) o de solo escritura (omitiendo el Getter).
2. **Validación Integrada:** El Setter actúa como un filtro que rechaza datos erróneos (como IDs negativos o arreglos vacíos) lanzando excepciones.
3. **Encapsulamiento y Mantenimiento:** Si la estructura interna de los datos cambia en el futuro, no rompes el código externo que ya consume los métodos públicos.
4. **Mutadores Internos Privados:** No todos los setters deben ser públicos. Métodos como `setFechaHoraActual()` son privados porque su ejecución es responsabilidad exclusiva de la clase durante la instanciación.

---

## 29.3. Anatomía y Estructura

```php
class Pedido
{
    private array $productos;

    // Getter: Devuelve el tipo de dato exacto de la propiedad
    public function getProductos(): array
    {
        return $this->productos;
    }

    // Setter Publico: Recibe el valor, valida y no retorna nada (void)
    public function setProductos(array $productos): void
    {
        if (empty($productos)) {
            throw new InvalidArgumentException("Un pedido debe contener al menos un producto.");
        }
        $this->productos = $productos;
    }
}
```

---

## 29.4. Ejemplo de Código

```php
<?php
declare(strict_types=1);

header("Content-Type: text/plain; charset=utf-8");

echo "======================================================================\n";
echo "29. POO: Getters y Setters\n";
echo "======================================================================\n\n";

class Pedido
{
    private int $idPedido = 0;
    private string $fechaHoraPedido;
    private array $productos;
    private float $total;
    private static int $cantidadPedidos = 0;

    public function __construct(array $productos)
    {
        $idPedido = ++self::$cantidadPedidos;  // Operador pre-incremento. Primero se suma +1 a la variable y después se asigna.

        $this->setIdPedido($idPedido);
        $this->setFechaHoraActual();
        $this->setProductos($productos);
        $this->setTotal();
    }

    // --- GETTERS (Accesores) ---

    public function getIdPedido(): int
    {
        return $this->idPedido;
    }

    public function getFechaHoraPedido(): string
    {
        return $this->fechaHoraPedido;
    }

    public function getProductos(): array
    {
        return $this->productos;
    }

    public function getTotal(): float
    {
        return $this->total;
    }

    public static function getCantidadPedidos(): int
    {
        return self::$cantidadPedidos;
    }

    // --- SETTERS (Mutadores con Validación) ---

    public function setIdPedido(int $idPedido): void
    {
        if ($idPedido < 0) {
            throw new InvalidArgumentException("El ID del pedido debe ser un entero positivo.");
        }
        $this->idPedido = $idPedido;
    }

    public function setProductos(array $productos): void
    {
        if (empty($productos)) {
            throw new InvalidArgumentException("Un pedido debe contener al menos un producto.");
        }
        $this->productos = $productos;
    }

    public function setTotal(): void
    {
        $total = 0;

        // Véase 017.Estructura-foreach.md para entender esta parte
        foreach ($this->productos as $producto => $cantidad) {
            $precio = match ($producto){
                "refrescos" => 25,
                "papas" => 35,
                "hamburguesas" => 60,
                default => throw new InvalidArgumentException("El producto '{$producto}' no es válido.")
            };
        $total += $precio * $cantidad; // Es lo mismo que: $total = $total + $precio * $cantidad;
        }

        if ($total <= 0) {
            throw new InvalidArgumentException("El total del pedido debe ser mayor a cero.");
        }

        $this->total = $total;
    }

    private function setFechaHoraActual(): void
    {
        $ahora = new DateTime();
        $this->fechaHoraPedido = $ahora->format('d/m/Y H:i:s');
    }
}

// --- EJECUCIÓN ---
$pedido1 = new Pedido(["hamburguesas" => 1, "papas" => 1, "refrescos" => 1]);
echo "\nPedido #{$pedido1->getIdPedido()} registrado el {$pedido1->getFechaHoraPedido()} por $" . number_format($pedido1->getTotal(), 2) . "\n";
echo "Contiene: \n";

$productos = $pedido1->getProductos();

foreach ($productos as $clave => $valor) {
    echo "$clave: $valor\n";
}

$pedido2 = new Pedido(["hamburguesas" => 2, "papas" => 2]);
echo "\nPedido #{$pedido2->getIdPedido()} registrado el {$pedido2->getFechaHoraPedido()} por $" . number_format($pedido2->getTotal(), 2) . "\n";
echo "Contiene: \n";

$productos = $pedido2->getProductos();

foreach ($productos as $clave => $valor) {
    echo "$clave: $valor\n";
}

echo "\nTotal de pedidos creados: " . Pedido::getCantidadPedidos() . "\n";
```
