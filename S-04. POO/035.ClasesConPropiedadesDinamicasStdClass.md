# 35. POO: Clases con Propiedades Dinámicas (`stdClass`)

## 35.1. ¿Qué es `stdClass`?

En PHP, **`stdClass`** es una clase genérica y vacía perteneciente al espacio de nombres global del lenguaje. Permite instanciar objetos a los cuales se les pueden añadir propiedades y valores dinámicamente ("al vuelo o según la necesidad") sin necesidad de haber definido previa o formalmente una estructura de clase mediante la palabra reservada `class`.

```php
$objeto = new stdClass();
$objeto->propiedadDinamica = "Valor asignado al vuelo";
```

---

## 35.2. Formas de Creación de Objetos `stdClass`

Existen tres formas principales de obtener o generar un objeto **`stdClass`**: 

- **Instanciación directa:** Creando una nueva instancia de la clase genérica.

```php
$usuario = new stdClass();
$usuario->nombre = "Ricardo";
```

- **Casting/Casteo de Array a Objeto (`(object)`):** Convierte las claves de un array asociativo en propiedades del objeto.

```php
$array = ['tipo' => 'AI', 'nombre' => 'Gemini'];
$objeto = (object) $array;
```

Nota: Si el array posee índices numéricos, sus propiedades deberán accederse mediante la sintaxis de llaves `{0}`, `{1}`.

- **Decodificación de cadenas JSON `(json_decode)`:** Por defecto, la función `json_decode()` sin el parámetro `associative = true` transforma la estructura JSON en instancias de `stdClass`.

```php
$datos = json_decode('{"id": 1, "status": "ok"}'); // Retorna stdClass
```

---

## 35.3. Tabla Comparativa: `stdClass` vs. Array Asociativo vs. DTO (Clase Concreta)

| Criterio | Array Asociativo | `stdClass` | DTO / Clase Concreta (PHP 8+) |
| :----------------- | :------------------ | :---------------- | :----------------------------- |
| Sintaxis de Acceso | `$datos['propiedad']` | `$datos->propiedad` | `$datos->propiedad` |
| Encapsulamiento y Métodos |❌ No tiene métodos | ❌ No tiene métodos | ✅ Métodos y encapsulamiento |
| Type Hinting Estricto | ❌ No distingue estructura | ❌ Solo declara `object` | ✅ Nombre de clase específico | 
| Seguridad ante Errores | ⚠️ Genera `Warning/Error` |❌ Crea una nueva propiedad silenciosamente | ✅ Error fatal/excepción si no existe |
| Soporte IDE / Autocompletado | ❌ No disponible | ❌ No disponible | ✅ Autocompletado total |

---

## 35.4. Ventajas, Desventajas y Consideraciones en PHP 8

Ventajas

- **Flexibilidad:** Permite estructurar datos dinámicos o semiestructurados sin crear archivos o definiciones de clases adicionales.
- **Compatibilidad con APIS:** Es la salida natural de bibliotecas y funciones nativas como `json_decode()` o drivers de base de datos (`PDO::FETCH_OBJ`).

Desventajas y Riesgos

- **Falta de Comportamiento:** Solo almacena atributos, no puede contener métodos ni lógica de negocio.
- **Sin Seguridad de Tipos (Type Hinting):** No se puede exigir la estructura interna de un `stdClass` en la firma de una función, invalidando los beneficios de la programación orientada a objetos.
- **Errores Silenciosos de Escritura:** Si cometes un error tipográfico al asignar o acceder a un atributo (por ejemplo, `$datos->usaurio`), PHP creará una nueva propiedad en lugar de advertir el error.

**Evolución en PHP 8.2+:** A partir de PHP 8.2, la creación de propiedades dinámicas en clases personalizadas fue deprecada. Aunque `stdClass` sigue permitiéndolas de manera excepcional por diseño histórico, la buena práctica moderna promueve el uso de clases con la palabra clave `readonly` o DTOs fuertemente tipados.

## 35.5. Ejemplo Práctico (035.ClasesConPropiedadesDinamicasStdClass.php)

```php
<?php
declare(strict_types=1);

header("Content-Type: text/plain; charset=utf-8");

echo "======================================================================\n";
echo "35. POO: Clases con Propiedades Dinámicas (stdClass)\n";
echo "======================================================================\n\n";

// --- 35.1 CREACIÓN DE OBJETOS stdClass ---

// Forma 1: Instanciación directa
$usuario = new stdClass();
$usuario->nombre = "Ricardo";
$usuario->edad = 34;
$usuario->activo = true;

echo "--- 1. Instanciación directa ---\n";
echo "Usuario: {$usuario->nombre}, {$usuario->edad} años. Activo: " . ($usuario->activo ? 'Sí' : 'No') . "\n";
echo "Tipo de \$usuario: " . gettype($usuario) . "\n\n";

// Forma 2: Casting de Array Asociativo a Objeto (object)
$arraySoftware = [
    'nombreSoftware' => 'Gemini',
    'tipo'           => 'AI',
    'version'        => 2.5
];

$objetoSoftware = (object) $arraySoftware;

echo "--- 2. Casting de Array Asociativo a Object ---\n";
echo "Software: {$objetoSoftware->nombreSoftware} ({$objetoSoftware->tipo}) v{$objetoSoftware->version}\n";
echo "Tipo de \$objetoSoftware: " . gettype($objetoSoftware) . "\n\n";

// Forma 2.1: Casting de Array Numérico (Claves numéricas)
$numeros = [66, 21, 25];
$objetoNumerico = (object) $numeros;

echo "--- 2.1. Casting de Array Numérico ---\n";
echo "Acceso a propiedad numérica {0}: {$objetoNumerico->{0}}\n";
echo "Acceso a propiedad numérica {1}: {$objetoNumerico->{1}}\n\n";

// Forma 3: Decodificación de JSON (json_decode)
$json = '{"nombre": "Ricardo", "edad": 34, "aplicativos": ["VS Code", "Gemini", "OBS"]}';

// Como Array (segundo parámetro = true)
$arrayJSON = json_decode($json, true);

// Como Objeto stdClass (segundo parámetro = false / omitido)
$objetoJSON = json_decode($json, false);

echo "--- 3. JSON Decodificado ---\n";
echo "Acceso por Array: " . $arrayJSON['nombre'] . " usa " . implode(", ", $arrayJSON['aplicativos']) . "\n";
echo "Acceso por Objeto stdClass: " . $objetoJSON->nombre . " usa " . implode(", ", $objetoJSON->aplicativos) . "\n\n";

// --- 35.2 DEMOSTRACIÓN DE RIESGOS EN stdClass ---

echo "--- 4. Riesgo de Errores Tipográficos (Sin Error de PHP) ---\n";
// Si escribimos mal un atributo, PHP NO lanza un error, simplemente crea una nueva propiedad
$usuario->usaurio = "ErrorTypo"; // Typo involuntario

echo "Propiedad correcta 'nombre': {$usuario->nombre}\n";
echo "Propiedad indeseada 'usaurio': {$usuario->usaurio}\n";
```

---

## 35.6. Análisis Técnico del Ejemplo

- **Uso de Casting:** La conversión `(object) $array` mapea cada clave como una propiedad pública en el objeto `stdClass` resultante.
- **Comportamiento ante JSON:** `json_decode()` produce instancias anidadas de `stdClass` para cada sub-objeto dentro de la cadena JSON.
- **Ausencia de Contrato:** Ninguna de las instancias generadas implementa interfaces ni hereda de una superclase, lo que las convierte en meras "bolsas de datos".
