# 23. POO: Destructores de Objetos

Así como los constructores se encargan de la creación e inicialización de objetos, los **destructores** en PHP son métodos especiales diseñados para la limpieza y liberación de recursos justo antes de que el objeto sea eliminado de la memoria.

---

## 23.1. Definición y Comportamiento del Destructor

> **Reflexión clave sobre el ciclo de vida:**
> La destrucción de un objeto **siempre ocurre de forma automática** en PHP cuando este deja de utilizarse o al terminar el script. La función del método mágico `__destruct()` no es providenciar la eliminación en sí, sino **permitir al desarrollador ejecutar código personalizado en el preciso instante en que esa destrucción sucede.**

Si no se define explícitamente un destructor, PHP realiza una **destrucción implícita** en silencio. Sin embargo, cuando se requiere ejecutar tareas explícitas de finalización, se define un **Destructor Explícito** mediante la sintaxis `__destruct()`.

En PHP, el destructor se define mediante el método mágico reservado `__destruct()`.

> **Reglas clave:**
>
> - `__destruct()` **NO** acepta parámetros.
> - `__destruct()` **NO** retorna ningún valor (`void`).

---

## 23.2. ¿Cuándo se Ejecuta un Destructor?

El motor Zend de PHP invoca automáticamente a `__destruct()` en dos situaciones:

1. **Destrucción Explícita / Forzada (Pérdida de referencias):** Cuando eliminamos la variable manualmente con `unset($objeto)` o cuando se le asigna un nuevo valor.
2. **Destrucción Implícita (Final del script):** Al concluir la ejecución completa del archivo PHP, todos los objetos activos en memoria se eliminan automáticamente.

---

## 23.3. Casos de Uso Reales: ¿Cuándo es Importante Usarlo?

El uso de destructores es fundamental en escenarios de gestión de recursos externos para evitar fugas de memoria o bloqueos en el servidor:

- **Cierre de Conexiones a Bases de Datos:** Garantizar que una conexión persistente (PDO o MySQLi) se cierre correctamente si la clase finaliza su ciclo de vida.
- **Manejo de Archivos (I/O):** Guardar un _buffer_ pendiente en disco y cerrar el puntero del archivo (`fclose($stream)`) para liberar el archivo y evitar que quede bloqueado por el sistema operativo.
- **Archivos Temporales y Caché:** Eliminar archivos temporales creados durante la ejecución de la clase (por ejemplo, imágenes en procesamiento o PDF generados) antes de liberar la memoria.
- **Registro de Bitácoras (Logging y Métricas):** Registrar el tiempo final de ejecución o enviar métricas de rendimiento/auditoría a un servidor de registros cuando una tarea o servicio termina.
- **Cierre de Sockets o Sesiones cURL:** Finalizar conexiones remotas abiertas de manera segura.

## 23.4. Ejemplo de Código

```php
class DesYConsDeClase {
    // Propiedades o atributos
    private $apellidoP;
    private $apellidoM;
    private $nombre;
    private $edad;

    // Métodos
    public function getPropiedadesPrivadasComoArray() {
        return [
            $this->apellidoP,
            $this->apellidoM,
            $this->nombre,
            $this->edad
        ];
    }

    // Constructor EXPLÍCITO
    public function __construct($apellidoPUsuario, $apellidoMUsuario, $nombreUsuario, $edadUsuario) {
        $this->apellidoP = $apellidoPUsuario;
        $this->apellidoM = $apellidoMUsuario;
        $this->nombre = $nombreUsuario;
        $this->edad = $edadUsuario;
    }

    // Destructor EXPLÍCITO
    public function __destruct() {
        echo "[DESTRUCTOR]: Se ha eliminado el objeto de la memoria.\n\n";
    }
}

// Instanciación
$objetoDeLaClase = new DesYConsDeClase("García", "López", "Ricardo", 34);

// Obtención de valores
$arrayParaVariasPropiedadesPrivadas = $objetoDeLaClase->getPropiedadesPrivadasComoArray();

// FORZAMOS LA DESTRUCCIÓN DEL OBJETO AQUÍ:
unset($objetoDeLaClase);    // Comenta está línea de código para destruir el objeto al final

echo "--- RESULTADOS EN CONSOLA ---\n";
echo "Acceso a propiedades privadas mediante getter:\n";
print_r($arrayParaVariasPropiedadesPrivadas);

foreach ($arrayParaVariasPropiedadesPrivadas as $indice => $valor) {
    echo "El valor en la posición " . ($indice + 1) . " es: $valor\n";
}

// Nota: El destructor se disparará automáticamente justo después de la última línea sí no se forza su destrucción previamente con unset()
```
