# 21. POO: Constructores Explícitos y Promoción de Propiedades (PHP 8.0+)

El **constructor** es un método fundamental en la Programación Orientada a Objetos encargado de inicializar el estado de una instancia al momento de su creación.

---

## 21.1. Definición de un Constructor en PHP

Un **constructor** es un método especial que se ejecuta automáticamente cuando se crea un objeto a partir de una clase mediante la palabra reservada **`new`**.

Si no se define un constructor en una clase, PHP proporciona uno **implícito**. Este constructor implícito no recibe parámetros y permite crear la instancia dejando sus propiedades sin inicializar (con su valor predeterminado o `null`).

Por otro lado, para establecer un estado inicial personalizado o requerir dependencias obligatorias, se define un **Constructor Explícito**. Este recibe parámetros y los asigna a los atributos del objeto, garantizando la integridad de los datos desde el primer instante.

> **Regla clave:** En PHP **NO** existe la sobrecarga de constructores como en lenguajes como C# o Java. Una clase solo puede tener un único método **`__construct()`**.

---

## 21.2. Relación con los Métodos Mágicos

El método **`__construct()`** pertenece al grupo de los **métodos mágicos** de PHP, identificables por el prefijo de doble guion bajo (`__`). Estos métodos no se invocan de forma explícita en el flujo normal, sino que PHP los dispara internamente ante eventos concretos del ciclo de vida del objeto (en este caso, la instanciación).

---

## 21.3. Sintaxis Tradicional vs. Promoción de Propiedades

### 21.3.1. Sintaxis Tradicional (PHP 7.4 y anteriores)

Para declarar e inicializar propiedades privadas, era necesario repetir la variable múltiples veces: en la declaración del atributo, como parámetro del constructor y en la asignación explícita con **`$this->`**.

```php
declare(strict_types=1);		// TIENE QUE SER la primera línea/instrucción de cada archivo PHP

class PersonaSintaxisTradicional {
    private string $apellidoP;
    private string $apellidoM;
    private string $nombre;
    private int $edad;

    public function __construct(string $apellidoP, string$apellidoM, string $nombre, int$edad) {
        $this->apellidoP = $apellidoP;
        $this->apellidoM = $apellidoM;
        $this->nombre = $nombre;
        $this->edad = $edad;
    }
}
```

### 21.3.2. Sintaxis Promocionada (PHP 8.0+)

A partir de PHP 8.0 se introdujo la Promoción de Propiedades en el Constructor (Constructor Property Promotion), un azúcar sintáctico (syntactic sugar) diseñado para reducir el código repetitivo (boilerplate) al declarar e inicializar propiedades en una clase.

Al anteceder un modificador de visibilidad (**`public`**, **`private`**, **`protected`**) o **`readonly`** a los parámetros del método **`__construct()`**, PHP ejecuta internamente la declaración de la propiedad y la asignación automática del argumento recibido.

```php
declare(strict_types=1);		// TIENE QUE SER la primera línea/instrucción de cada archivo PHP

class PersonaSintaxisPromocionada {
    // PHP automáticamente declara las propiedades privadas y les asigna los valores
    public function __construct(
        private string $apellidoP,
        private string $apellidoM,
        private string $nombre,
        private int $edad
    ) {
        // El cuerpo del constructor puede quedar vacío
    }
}
```

---

## 21.4. Reglas y Consideraciones Clave

- **Uso Exclusivo**: Solo se permite dentro del método mágico \_\_construct(). No funciona en métodos regulares.
- **Lógica Adicional**: Si necesitas validar datos al instanciar, puedes escribir código dentro de las llaves {} del constructor; la asignación de las propiedades promocionadas ocurre antes de ejecutar dicho bloque.
- **Mezcla de Parámetros**: Es posible combinar parámetros promocionados (con visibilidad) y parámetros normales (sin visibilidad) dentro del mismo constructor.
