# 39. POO y Web: La Interfaz `JsonSerializable`

## 39.1. El Problema de la Serialización Predeterminada

Por defecto, al pasar un objeto a la función `json_encode()`, PHP únicamente incluye sus propiedades de visibilidad **pública** (`public`). Las propiedades **protegidas** (`protected`) y **privadas** (`private`) **son omitidas por completo para preservar el encapsulamiento**.

En un diseño Orientado a Objetos robusto, la mayoría de los atributos permanecen ocultos tras visibilidades restringidas. Si una clase no posee atributos públicos, `json_encode()` devolverá un objeto JSON vacío (`{}`).

---

## 39.2. La Interfaz `JsonSerializable`

Para resolver esta limitación, PHP provee la interfaz nativa `JsonSerializable`. Al implementarla, la clase asume el control explícito sobre la representación JSON del objeto.

```php
interface JsonSerializable
{
    public function jsonSerialize(): mixed;
}
```

Firma del Método `jsonSerialize()`
Valor de retorno (`mixed`): Debe devolver cualquier dato que sea serializable por `json_encode()` (habitualmente un `array` asociativo, aunque también puede ser una cadena, entero, booleano u otro objeto que implemente la interfaz).

---

## 39.3. Ventajas y Casos de Uso

- **Control de Encapsulamiento:** Permite exponer atributos `protected` o `private` específicos sin obligar a cambiarlos a `public`.
- **Filtrado de Datos Sensibles:** Facilita la exclusión de información confidencial (hash de contraseñas, tokens de sesión, datos bancarios).
- **Propiedades Virtuales / Calculadas:** Permite incorporar valores derivados que no existen como atributos físicos de la clase (por ejemplo, `nombre_completo` concatenado o un estado dinámico).
- **Transformación de Formatos:** Modifica valores complejos antes de exportarlos (por ejemplo, formatear un objeto `DateTimeImmutable` a una cadena en estándar ISO-8601).
- **Recursividad Automática:** Si un objeto serializable contiene otras instancias que también implementan `JsonSerializable`, PHP invocará `jsonSerialize()` en cascada de manera transparente.

---

## 39.4. Ejemplo Práctico

```php
class Producto implements JsonSerializable
{
    public function __construct(
        private int $id,
        private string $nombre,
        private float $precio
    ) {}

    public function jsonSerialize(): mixed
    {
        return [
            'id' => $this->id,
            'nombre' => $this->nombre,
            'precio_formateado' => '$' . number_format($this->precio, 2),
            'en_stock' => $this->precio > 0
        ];
    }
}
```
