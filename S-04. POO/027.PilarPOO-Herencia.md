# 27. POO: Herencia

La **Herencia** es uno de los pilares fundamentales de la Programación Orientada a Objetos (POO). Permite que una **subclase** (**clase hija**) herede propiedades y métodos de una **superclase** (**clase padre**), promoviendo la reutilización de código y facilitando la extensión de funcionalidades.

---

## 27.1. Definición y Palabras Clave

- **`extends`:** Palabra reservada para indicar que una subclase hereda de una clase padre.
- **`parent::`:** Operador que permite invocar métodos o constructores de la clase padre dentro de la subclase (imprescindible para extensión de comportamiento).

---

## 27.2. Matriz de Visibilidad y Niveles de Acceso (Repaso 20.3)

| Visibilidad     | Dentro de la propia Clase | Desde Subclases (`extends`) | Ámbito Global (Instancia externa) |
| :-------------- | :-----------------------: | :-------------------------: | :-------------------------------: |
| **`public`**    |            Sí             |             Sí              |                Sí                 |
| **`protected`** |            Sí             |             Sí              |                No                 |
| **`private`**   |            Sí             |             No              |                No                 |

---

## 27.3. Diferencia entre Acceso vs. Encapsulación

- **Acceso / Visibilidad (`public`, `protected`, `private`):** Reglas del lenguaje que determinan qué ámbitos pueden leer o escribir miembros de una clase.
- **Encapsulación:** Patrón de diseño donde se oculta la implementación interna y se expone una interfaz pública regulada (Getters, Setters y Wrappers) para proteger la integridad de los datos.

---

## 27.4. Modos de Acceso

1. **Acceso Directo:** Ocurre cuando se invoca un miembro utilizando el operador de objeto (`->`) o el operador de resolución de ámbito (`::`) en un entorno que cuenta con el permiso explícito.
2. **Acceso Indirecto:** Se realiza mediante métodos mediadores (`public` o `protected`), como los métodos accesores (**Getters** y **Setters**), para consultar o alterar miembros restringidos (`private` o `protected`).

---

## 27.5. Operadores de Ámbito: `->` vs `::`

### 27.5.1. Operador de Objeto (`->`)

Se utiliza para interactuar con propiedades y métodos asociados a una **instancia en memoria** (`$this` o `$objeto`).

- `$this->propiedadProtegida;`

### 27.5.2. Operador de Resolución de Ámbito (`::`)

Se utiliza para referenciar ámbitos estáticos, constantes o resoluciones de jerarquía de herencia.

- `parent::metodoPadre();`
- `self::METODO_ESTATICO();`

> **Regla de Oro en Propiedades y Métodos:**
>
> - Los **métodos** existen como definiciones ESTÁTICAS en el ámbito de la clase, por lo que se pueden invocar con `parent::metodoPadre()`.
> - Las **propiedades** residen en la instancia del objeto, por lo que siempre se acceden con `$this->propiedad` (incluso si pertenecen originalmente a la clase padre). Intenta usar `parent::$propiedad` en miembros no estáticos provocará un error.

---

## 27.6. Definición Formal de Sobreescritura (_Method Overriding_)

Existe sobreescritura **únicamente cuando hay una relación de herencia (`extends`)** entre las clases.

- **Mismo nombre en clases independientes (NO es sobreescritura):** Si la clase `Auto` y la clase `Usuario` contienen un método llamado `cancelar()`, son métodos totalmente ajenos que coinciden por casualidad.
- **Mismo nombre en una jerarquía de herencia (SÍ es sobreescritura):** Cuando `ClaseHija` define un método con el mismo nombre y firma que `ClasePadre`, reemplaza la implementación en la tabla de símbolos del objeto para esa instancia.

---

## 27.7. Sobreescritura vs. Extensión de Métodos

| Mecanismo          | Definición                                                        | Implementación en PHP                                                |
| :----------------- | :---------------------------------------------------------------- | :------------------------------------------------------------------- |
| **Sobreescritura** | Reemplaza totalmente el comportamiento de un método heredado.     | Se define el método en la subclase **sin** invocar al padre.         |
| **Extensión**      | Conserva el comportamiento original y agrega nueva funcionalidad. | Se define el método en la subclase **invocando** `parent::metodo()`. |

---

## 27.8. Ejemplo de Código

```php
<?php
declare(strict_types=1);

header("Content-Type: text/plain; charset=utf-8");

echo "======================================================================\n";
echo "27. POO: Herencia\n";
echo "======================================================================\n\n";

class Humano  // Clase padre (SUPERCLASE)
{
    // 1. Propiedades (atributos) de la clase
    protected string $especie = "Homo sapiens";

    // 2. Métodos (funciones) de la clase
    public function hablar(): string
    {
        return "\"Sonidos genéricos\"\n\n";
    }

    // 3. Getters y setter (Acceso a propiedad protegida por clases hijas)
    public function obtenerEspecie(): string
    {
        return $this->especie;
    }
}

class Mexicano extends Humano // Clase hija (SUBCLASE)
{
    // 1. Propiedades (atributos) de la clase
    protected string $pais = "México";

    // 2. Métodos (funciones) de la clase
    // A. SOBREESCRITURA del método (Se reemplaza por completo el método hablar() de la clase padre)
    public function hablar(): string
    {
        return "\n¡Que tranza wey! Yo hablo español.";
    }

    // 3. Getters y setter (Acceso a propiedad protegida por clases hijas)
    public function obtenerPais(): string
    {
        return $this->pais;
    }
}

class MexicoAmericano extends Mexicano // Clase nieta (SUB-SUBCLASE)
{
    // 1. Propiedades (atributos) de la clase: NO HAY

    // 2. Métodos (funciones) de la clase: NO HAY
    // B. EXTENSIÓN de Método (Conserva la lógica del padre y agrega más)
    public function hablar(): string
    {
        return parent::hablar() . ".. and English, too! ";
    }

    // 3. Getters y setter (Acceso a propiedad protegida por clases hijas): NO HAY
}

$mexicano1 = new Mexicano();
echo $mexicano1->hablar();  // Salida: "¡Que tranza wey! Yo hablo español"
echo " Yo nací en " . $mexicano1->obtenerPais() . " y soy " . $mexicano1->obtenerEspecie() . "\n\n";

$mexicano2 = new MexicoAmericano();
echo $mexicano2->hablar();  // Salida: "¡Que tranza wey! Yo hablo español... and English, too!"
echo " Yo nací en " . $mexicano2->obtenerPais() . " y soy " . $mexicano2->obtenerEspecie() . "\n\n";
```
