# 38. POO y Web: Codificación y Decodificación con `json_encode()` y `json_decode()`

## 38.1. Transformación de Datos en PHP y JSON

El intercambio de datos en aplicaciones web modernas se basa en transformar estructuras en memoria (arrays asociativos u objetos) a cadenas de texto plano estandarizadas en formato JSON y viceversa.

---

## 38.2. Codificación con `json_encode()`

La función `json_encode()` toma un valor de PHP y lo convierte en una representación JSON.

```php
string|false json_encode(mixed $value, int $flags = 0, int $depth = 512)
```

### 38.2.1. Flags de Máscara de Bits (Bitmask Flags) Más Utilizados

| Flag | Descripción | 
| :-------------------------------- | :--------------------------------------------------------------------------------------------------- |
| **`JSON_PRETTY_PRINT`** | Formatea el JSON resultante con sangría de 4 espacios y saltos de línea para facilitar su lectura. | 
| **`JSON_UNESCAPED_UNICODE`** | Mantiene caracteres multibyte (como acentos, eñes o emojis) sin codificar a secuencias `\uXXXX`. |
| **`JSON_THROW_ON_ERROR`** | Lanza una excepción JsonException en lugar de retornar false ante fallos de codificación. |
| **`JSON_PRESERVE_ZERO_FRACTION`** | Conserva el punto decimal en números flotantes enteros (por ejemplo: `10.0`). |

---

## 38.3. Decodificación con `json_decode()`

La función `json_decode()` interpreta una cadena JSON y la convierte en una estructura nativa de PHP.

```php
mixed json_decode(string $json, ?bool $associative = null, int $depth = 512, int $flags = 0)
```

Comportamiento del Parámetro `$associative`
- `false` (o `null` por defecto): Devuelve objetos instanciados automáticamente como `stdClass`. Las claves de JSON se convierten en propiedades del objeto (`$objeto->clave`).
- `true`: Devuelve arrays asociativos multidimensionales (`$array['clave']`).

---

## 38.4. Control y Manejo de Errores

Existen dos estrategias para detectar fallos en sintaxis JSON:

- Método Tradicional (Procedural)
Utiliza las funciones `json_last_error()` y `json_last_error_msg()` tras invocar la codificación o decodificación.

```php
$data = json_decode($jsonInvalido);
if (json_last_error() !== JSON_ERROR_NONE) {
    echo "Error: " . json_last_error_msg();
}
```

- Método Moderno (Basado en Excepciones)

Pasando el flag `JSON_THROW_ON_ERROR`, cualquier error de sintaxis lanzará un objeto `JsonException`, permitiendo una captura limpia mediante bloques `try/catch`.

---

## 38.5. Serialización de Objetos y Visibilidad

Al aplicar `json_encode()` sobre una instancia de una clase personalizada, únicamente las propiedades con visibilidad `public` serán serializadas en el JSON resultante. Las propiedades `protected` y `private` son ignoradas de manera predeterminada para evitar la fuga involuntaria de datos sensibles (como contraseñas o claves privadas).
