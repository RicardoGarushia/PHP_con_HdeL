# 33. POO: Polimorfismo y Sobreescritura de Métodos

## 33.1. ¿Qué es el Polimorfismo?

El **polimorfismo** (del griego *poly* = muchas, *morphe* = formas) es un pilar fundamental de la Programación Orientada a Objetos que describe la capacidad de diferentes objetos de responder al mismo mensaje o invocación de método ejecutando comportamientos distintos según el contexto en tiempo de ejecución.

En términos arquitectónicos, las clases definen e implementan el polimorfismo a través de sus métodos, mientras que los objetos exhiben este comportamiento cuando son consumidos.

### La Interfaz Común
Para que el polimorfismo sea posible, las distintas clases deben compartir una **interfaz común** o contrato que defina las firmas de los métodos disponibles. Esto permite tratar objetos heterogéneos de manera uniforme dentro del sistema.

---

## 33.2. Mecanismos para Lograr Polimorfismo en PHP

En PHP, el polimorfismo se manifiesta a través de tres mecanismos estructurados:

| Mecanismo | Formato de Implementación | Explicación Técnica |
| :--- | :--- | :--- |
| **Herencia (`extends`)** | **Sobreescritura de Métodos** | Una subclase redefine la lógica de un método heredado de una superclase. |
| **Interfaces (`implements`)** | **Contratos de Método** | Diversas clases implementan la firma obligatoria definida en la interfaz. |
| **Traits (`use`)** | **Composición Horizontal** | Varias clases incorporan un mismo trait que define un comportamiento compartido. |

La clave del polimorfismo radica en que, aunque las clases compartan la **misma firma de método** (mismo nombre y mismos parámetros), cada una ejecuta una lógica interna adaptada a su propia naturaleza.

---

## 33.3. ¿Qué es la Sobreescritura de Métodos (*Method Overriding*)?

La **sobreescritura de métodos** ocurre cuando una subclase proporciona una implementación específica para un método que ya ha sido definido en su superclase o clase padre.

Mediante este proceso, la subclase "reemplaza" o adapta el comportamiento heredado para ajustarlo a sus requerimientos particulares.

---

## 33.4. Reglas Obligatorias para la Sobreescritura

Para que una redefinición de método sea considerada una **sobreescritura válida** en PHP, debe cumplir estrictamente con tres condiciones:

1. **Relación de Herencia:** Debe existir una jerarquía de clases activa mediante la palabra reservada `extends`.
2. **Coincidencia Exacta de Firma (*Signature Match*):**
   - Mismo **nombre** de método.
   - Mismo número, orden y **tipos de datos de los parámetros**.
   - Mismo **tipo de dato de retorno** (o subtipo compatible).
3. **Regla de Covarianza de Visibilidad:** La visibilidad del método en la subclase debe ser **igual o más accesible** que en la superclase.
   - *Ejemplo:* Si el método padre es `protected`, la subclase puede redefinirlo como `protected` o `public`, pero **nunca** como `private`.

> ⚠️ **Nota:** Si alguna de estas condiciones se incumple o altera la firma del método, no se estará realizando sobreescritura válida.

---

## 33.5. Ejemplo Práctico (`033.Polimorfismo_Sobreescritura.php`)

```php
<?php
declare(strict_types=1);

header("Content-Type: text/plain; charset=utf-8");

echo "======================================================================\n";
echo "33. POO: Polimorfismo y Sobreescritura de Métodos\n";
echo "======================================================================\n\n";

// Superclase abstracta
abstract class AreaFormaGeometrica
{
    protected float $area;

    // Método base
    public function calcularArea(float $base, float $altura): float
    {
        return ($base * $altura);
    }
}

// Subclase que hereda el método base sin sobreescribirlo
class Rectangulo extends AreaFormaGeometrica
{
}

// Subclase que sobreescribe el método
class Triangulo extends AreaFormaGeometrica
{
    // Sobreescritura manteniendo firma exacta
    public function calcularArea(float $base, float $altura): float
    {
        return ($base * $altura) / 2;
    }
}

// Ejecución polimórfica
$rectangulo = new Rectangulo();
$triangulo  = new Triangulo();

echo "Área del Rectángulo (Método Base): " . $rectangulo->calcularArea(5, 10) . "\n";
echo "Área del Triángulo (Sobreescrito): " . $triangulo->calcularArea(5, 10) . "\n";
```

---

## 32.6. Análisis Técnico del Ejemplo

- **Reutilización Heredada:** La clase `Rectangulo` no define un método `calcularArea()` propio; por lo tanto, ejecuta directamente la implementación de la superclase `AreaFormaGeometrica` `($base * $altura)`.
- **Especialización por Sobreescritura:** La clase `Triangulo` extiende de la clase `AreaFormaGeometrica` pero redefine/sobreescribe `calcularArea()`, dividiendo el resultado entre 2 para responder a la fórmula geométrica de los triángulos.
- **Mantenimiento de Firma:** `Triangulo::calcularArea()` respeta escrupulosamente los parámetros `(float $base, float $altura)` y el retorno `: float`, cumpliendo el contrato exigido para la sobreescritura.
