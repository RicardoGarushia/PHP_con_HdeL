# 25. Tipado de Datos en Clases: Propiedades, Parámetros y Retornos

A partir de PHP 7.4 (y reforzado en PHP 8.0+), es posible declarar explícitamente el **tipo de dato** en las propiedades de una clase, en los parámetros de sus métodos y en los valores de retorno. Esto asegura la integridad de los datos, evita errores silenciosos y mejora la legibilidad e autocompletado en los entornos de desarrollo.

---

## 25.1. El Constructo `declare(strict_types=1);`

Por defecto, PHP realiza una conversión implícita de tipos (*type casting*). Por ejemplo, si un método espera un `int` y le pasas el `string "21"`, PHP lo convertirá automáticamente a un entero.

Para desactivar este comportamiento predeterminado y exigir coincidencia **exacta** de tipos, se utiliza la directiva `strict_types=1` mediante el constructo `declare()`.

> **Regla de Sintaxis Crítica:**
> `declare(strict_types=1);` **DEBE ser la primerísima sentencia del archivo**, ubicada justo al inicio del bloque `<?php`. No se permite ningún espacio en blanco, comentario o salida de texto previa a esta instrucción en el archivo.

---

## 25.2. Tipado en Propiedades, Métodos y Retornos

El tipado explícito se aplica directamente en la estructura de la clase:

1. **Propiedades Tipadas:** Se define el tipo antes del nombre de la variable (`private string $nombre;`).
2. **Parámetros Tipados:** Se especifica el tipo esperado en la firma de la función/método (`string $nombreCliente`).
3. **Tipo de Retorno:** Se indica el tipo de dato que devolverá la función agregando dos puntos y el tipo antes de la llave de apertura (`public function obtenerDatos(): array`).

---

## 25.3. Ejemplo de Código

```php
<?php
declare(strict_types=1);

class Persona {
    // Propiedades con tipo de dato explícito
    private string $nombre;
    private int $edad;
    private float $monto;

    // Constructor con parámetros tipados
    public function __construct(string $nombreCliente, int $edadCliente, float $montoCliente) {
        $this->nombre = $nombreCliente;
        $this->edad = $edadCliente;
        $this->monto = $montoCliente;
    }

    // Método con tipo de retorno explícito (array)
    public function obtenerDatosCliente(): array {
        return [
            $this->nombre,
            $this->edad,$this->monto
        ];
    }
}

// Instanciación válida (los tipos coinciden exactamente)
$persona = new Persona("Ricardo", 34, 10000.65);

// Intentos inválidos con strict_types=1 (arrojan TypeError):
// $personaError1 = new Persona(1234, "21", "2566"); 
// $personaError2 = new Persona("Ricardo", 34.5, 10000);
```
