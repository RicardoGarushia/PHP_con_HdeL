# 37. POO y Web: Fundamentos de JSON (JavaScript Object Notation)

## 37.1. Introducción a JSON

**JSON** (*JavaScript Object Notation*) es un formato de texto plano ligero, estandarizado y fácil de leer por humanos y máquinas. Aunque deriva de la sintaxis de objetos de JavaScript, es un formato **independiente del lenguaje**, constituyendo el estándar principal para el intercambio de datos en APIs REST y comunicación cliente-servidor.

---

## 37.2. Estructuras Principales y Sintaxis

JSON soporta dos estructuras compuestas fundamentales:

1. **Objetos (`{}`):** Colecciones no ordenadas de pares clave/valor. En PHP se mapean como objetos `stdClass` o arrays asociativos.
2. **Arrays (`[]`):** Listas ordenadas de valores. En PHP se mapean como arrays indexados numéricamente.

```json
{   // Objeto
    "nombre": "Ricardo",
    "edad": 36,
    "estudianteActivo": true,
    "direccion": {  // Objeto
        "calle": "Av. Siempre Viva 123",
        "ciudad": "Springfield"
    },
    "hobbies": ["frontón", "lectura"]   // Array
}
```

---

## 37.3. Tipos de Datos Soportados

| Tipo de Dato JSON | Descripción | Ejemplo |
| :-------------------- | :------------------------------- | :------------------------------------- |
| **String** | Cadena de texto delimitada estrictamente por comillas dobles. | `"Ricardo"` | 
| **Number** | Entero o de punto flotante sin comillas. | `34, 8500.50` |
| **Boolean** | Valor lógico. | `true` / `false` |
| **Null** | Representación de valor ausente o nulo. | `null` |
| **Object** | Colección anidada de clave/valor en llaves `{}`. | `{"clave": "valor"}` |
| **Array** | Colección indexada en corchetes `[]`. | `[1, 2, 3]` |

> ⚠️ **Nota de sintaxis:** A diferencia de PHP, JSON prohíbe comas finales (trailing commas) al último elemento de una lista u objeto.

---

## 37.4. Arrays de Objetos JSON

Un array de objetos es la estructura estándar empleada para transferir colecciones de registros o entidades complejas desde la base de datos hacia el cliente[cite: 15].

```json
[   // Array
    {   // Objeto #1
        "id": 1,
        "nombre": "Monitor Gamer",
        "precio": 8500.50
    },
    {   // Objeto #2
        "id": 2,
        "nombre": "Teclado Mecánico",
        "precio": 1200.00
    }
]
```

---

## 37.5. Mapeo con Funciones Nativas de PHP

PHP ofrece dos funciones nativas principales dentro de su extensión Core JSON[cite: 15]:

- `json_encode()`: Transforma tipos de datos de PHP (arrays asociativos, objetos `stdClass`, entidades con visibilidad pública) en una cadena codificada en JSON.
- `json_decode()`: Interpreta un string JSON válido y lo transforma en un objeto `stdClass` o en un array asociativo multidimensional (cuando se especifica true como segundo argumento).
