# 28. POO: Encapsulamiento

El **Encapsulamiento** es uno de los pilares fundamentales de la Programación Orientada a Objetos (POO). Consiste en agrupar datos (propiedades) y comportamientos (métodos) dentro de una misma unidad (clase), restringiendo el acceso directo a sus componentes internos para proteger la integridad del estado del objeto (_Information Hiding_).

---

## 28.1. Definición

El encapsulamiento combina dos conceptos clave:

1. **Agrupación:** Reunir datos y las funciones que operan sobre esos datos dentro de una clase.
2. **Ocultamiento de información (_Information Hiding_):** Restringir el acceso directo a los atributos internos, obligando a interactuar con ellos únicamente a través de la interfaz pública expuesta (métodos accesores como Getters y Setters).

---

## 28.2. Objetivos Principales

- **Agrupar y organizar el código:** Convierte a la clase en una unidad autocontenida que representa una entidad con responsabilidades claras.
- **Proteger la integridad de los datos:** Evita estados inconsistentes al impedir la modificación directa o no autorizada de las propiedades desde el exterior.

---

## 28.3. Beneficios

- **Modularidad:** Unidades independientes fáciles de aislar, probar y reutilizar.
- **Ocultamiento de la complejidad:** El cliente consumidor solo necesita conocer la interfaz pública, ignorando la lógica interna.
- **Control de acceso:** Permite delimitar de forma estricta qué partes son expuestas y cuáles permanecen privadas.
- **Mantenibilidad y Flexibilidad:** Es posible refactorizar la implementación interna sin romper el código externo, siempre que la interfaz pública se mantenga.
- **Reusabilidad:** Facilita la integración de la clase en múltiples contextos del sistema.

---

## 28.4. Tipos de Visibilidad y Niveles de Acceso

### Visibilidad

Mecanismo que especifica el alcance (_scope_) desde donde se puede consultar o modificar un miembro de la clase:

- **`private`:** Miembro accesible **únicamente desde la propia clase** donde fue definido. Es el nivel de mayor restricción y el que mejor fortalece el encapsulamiento.
- **`protected`:** Accesible dentro de la propia clase y por subclases que la hereden (`extends`).
- **`public`:** Accesible desde cualquier parte del programa (ámbito global y clases externas).

### Niveles de Acceso

- **Acceso Directo:** Se realiza mediante el operador de objeto (`->`) o de ámbito (`::`) sobre un miembro, siempre que el ámbito actual tenga permiso explícito de visibilidad.
- **Acceso Indirecto:** Se realiza utilizando un intermediario (método `public` o `protected`) para consultar o alterar un miembro restringido (`private` o `protected`) al que no se tiene acceso directo.

---

## 28.5. Operadores: `->` vs `=`

- **Operador de Acceso a Miembros (`->`):** Se usa para acceder a propiedades o invocar métodos de una instancia determinada.
- **Operador de Asignación (`=`):** Se usa para asignar un valor a una variable o escribir directamente sobre una propiedad de un objeto (si su visibilidad lo permite).

---

## 28.6. Ejemplo de Código

```php
<?php
declare(strict_types=1);

header("Content-Type: text/plain; charset=utf-8");

echo "======================================================================\n";
echo "28. POO: Encapsulamiento\n";
echo "======================================================================\n\n";

class Persona
{
    private string $curp;
    private string $nombre;
    private string $apellidoP;
    private string $apellidoM;
    private float $estatura;
    private float $peso;
    private float $IMC;

    public function __construct(
        string $curpCliente,
        string $nombreCliente,
        string $apellidoPCliente,
        string $apellidoMCliente,
        float $estaturaCliente,
        float $pesoCliente
    ) {
        $this->curp =$curpCliente;
        $this->nombre =$nombreCliente;
        $this->apellidoP =$apellidoPCliente;
        $this->apellidoM =$apellidoMCliente;
        $this->estatura =$estaturaCliente;
        $this->peso =$pesoCliente;
        $this->IMC =$pesoCliente / ($estaturaCliente * $estaturaCliente);
    }

    public function getNombreCompleto(): array
    {
        return [
            $this->apellidoP,
            $this->apellidoM,$this->nombre
        ];
    }

    public function getIMC(): float
    {
        return $this->IMC;
    }
}

// Ejecución
$cliente = new Persona("GALR901123HDF", "Ricardo", "García", "López", 1.71, 84.5);

$arrayCliente =$cliente->getNombreCompleto();
echo "El cliente: ";
foreach ($arrayCliente as$valor) {
    echo "$valor ";
}
echo "\nTiene un IMC de: " . number_format($cliente->getIMC(), 2) . "\n";
```
