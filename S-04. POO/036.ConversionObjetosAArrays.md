# 36. POO: Conversión de Objetos a Arrays y Efectos de Visibilidad

## 36.1. Introducción

En PHP, la conversión de una instancia de objeto a un array asociativo es un procedimiento frecuente cuando se necesita serializar información, enviar respuestas en APIs o interactuar con funciones que solo aceptan arrays.

Sin embargo, al aplicar un casting explícito `(array)` sobre una clase concreta, PHP implementa reglas estrictas según la **visibilidad de las propiedades** (`public`, `protected`, `private`), modificando los nombres de las claves en el array resultante.

---

## 36.2. Comportamiento del Casting `(array)` según Visibilidad

Cuando se ejecuta `$array = (array) $objeto;`, PHP mapea cada atributo siguiendo estas reglas:

1. **Propiedades Públicas (`public`):** Se mantienen intactas. El nombre del atributo se convierte en la clave directa del array.
2. **Propiedades Protegidas (`protected`):** PHP agrega un prefijo con un asterisco entre caracteres nulos `\0*\0` antes del nombre del atributo (ejemplo: `\0*\0precio`).
3. **Propiedades Privadas (`private`):** PHP agrega un prefijo con el nombre de la clase delimitado por caracteres nulos `\0NombreClase\0` antes del nombre del atributo (ejemplo: `\0Producto\0stock`).

> ⚠️ **Nota:** Los caracteres nulos (`\0`) no son visibles en impresiones simples de texto, pero afectan las búsquedas de claves mediante `$array['precio']` o `$array['stock']`, las cuales fallarán si no se incluye el prefijo correspondiente.

---

## 36.3. Métodos Comparativos de Conversión

Existen tres formas comunes de convertir un objeto a array[cite: 11]:

| Método | Propiedades Incluidas | Formato de Claves | Conserva Lógica / Métodos |
| :-------------------- | :------------------------------- | :------------------------------------- | :-------------------------- |
| **Casting `(array)`** | `public`, `protected`, `private` | Modificado con prefijos `\0` | ❌ No (se omiten) |
| **`get_object_vars()`** | Únicamente `public` (desde ámbito externo) | Nombres de clave limpios | ❌ No (se omiten) |
| **JSON (`json_encode/decode`)**| Únicamente `public` | Nombres de clave limpios | ❌ No (se omiten) |

---

## 36.4. Omisión de Métodos y Pérdida de Comportamiento

Los métodos definidos dentro de una clase (como `mostrarProducto()`) **NO SE INCLUYEN** al convertir un objeto a un array. 

Un array en PHP solo puede almacenar datos (estado), por lo que la conversión actúa como una "fotografía" o captura estática de las propiedades del objeto en un instante determinado, descartando por completo el comportamiento de la clase.

---

## 36.5. Ejemplo Práctico (`036.ConversionObjetosAArrays.php`)

```php
<?php
declare(strict_types=1);

header("Content-Type: text/plain; charset=utf-8");

class Producto
{
    public string $nombre = "Monitor Gamer";
    protected float $precio = 8500.50;
    private int $stock = 12;
}

$monitor = new Producto();

// Casting a Array
$arrayProducto = (array) $monitor;

print_r($arrayProducto);

```

--- 

## 36.6. Análisis Técnico del Ejemplo

- **Incompatibilidad con claves protegidas/privadas:** Intentar acceder a `$arrayProducto['precio']` arrojará un error de clave indefinida (`Undefined array key`), ya que la clave real incluye prefijos invisibles de caracteres nulos (`"\0*\0precio"`).
- **Uso en código profesional:** Debido a la alteración de claves y la falta de control sobre los datos privados/protegidos, el casting `(array)` directo rara vez se utiliza para objetos con encapsulamiento. Para estos escenarios se prefiere implementar interfaces como `JsonSerializable` o métodos personalizados de conversión (ej. `toArray()`).
