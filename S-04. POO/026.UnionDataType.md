# 26. Tipos de Dato Unión (`Union Types`)

Introducidos oficialmente en **PHP 8.0**, los **Union Types** permiten declarar que una propiedad, parámetro o valor de retorno puede aceptar múltiples tipos de datos explícitos utilizando el operador de barra vertical (`|`).

---

## 26.1. Definición y Diferencia: Unión vs. Intersección

> **Aclaración Teórica:**
> - **Unión (`TypeA | TypeB`):** Opera como un **OR lógico**. El valor debe pertenecer a **al menos uno** de los tipos listados (ej. `int|float`).
> - **Intersección (`TypeA & TypeB`):** Opera como un **AND lógico** (introducido en PHP 8.1). El valor debe cumplir con **todos** los tipos especificados simultáneamente (usado con Interfaces).

 Un tipo unión flexibiliza el código permitiendo firmas mixtas sin perder la seguridad del tipado estricto.

---

## 26.2. Tipos Permitidos en una Unión

Se pueden combinar:
- **Tipos escalares:** `int`, `float`, `string`, `bool`.
- **Tipos compuestos:** `array`, `object`, `callable`, `iterable`.
- **Tipos especiales:** `null`, nombres de Clases e Interfaces.

---

## 26.3. Interacción entre Union Types y `declare(strict_types=1)`

Cuando usas `strict_types=1`, el *type casting* automático se deshabilita, pero los **Union Types** aportan la flexibilidad exacta que necesitas: restringen el valor para que sea **únicamente** uno de los tipos autorizados de la lista, rechazando cualquier otro.

---

## 26.4. Ejemplo de Código

```php
<?php
declare(strict_types=1);

class CalculadoraImpuestoIVA {
    // Propiedad que acepta entero o flotante
    private int|float $monto;

    // El parámetro puede ser int o float, y el retorno puede ser int, float o string
    public function procesarMonto(int|float $monto): int|float|string {
        $this->monto =$monto;

        if ($this->monto <= 0) {
            return "El monto debe ser mayor a cero.";
        }

        return $this->monto * 1.16; // Retorna el monto con IVA
    }
}

$calc = new CalculadoraImpuestoIVA();

// Ambos llamados son válidos con strict_types=1
echo $calc->procesarMonto(100);     // Acepta int
echo $calc->procesarMonto(50.50);   // Acepta float
echo $calc->procesarMonto("50.50"); // NO ACEPTA float
```
