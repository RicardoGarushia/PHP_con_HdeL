# 12. BUCLE `DO-WHILE` EN PHP

El **bucle `do-while`** es una estructura de control repetitiva (iterativa) similar al bucle `while`, con la diferencia fundamental de que **la condición se evalúa al final de cada iteración**. Esto garantiza que el bloque de código **se ejecute al menos una vez**, independientemente de si la condición es verdadera (_true_) o falsa (_false_) desde el inicio.

---

## 12.1. Sintaxis Básica del Bucle `do-while`

```php
<?php
do {
    // Código a ejecutar (se ejecuta al menos una vez)
} while (condicion);
?>
```

Bloque `do-`: Contiene las instrucciones que se ejecutan inmediatamente en la primera pasada.

Condición `-while`: Se evalúa después de ejecutar el bloque. Si devuelve _true_, repite el ciclo; si devuelve _false_, finaliza la ejecución. Note que la línea del `-while` debe terminar con un punto y coma ;.

---

## 12.2. Diferencia Clave entre `while` y `do-while`

| Característica              | Bucle `while`                   | Bucle `do-while`             |
| :-------------------------- | :------------------------------ | :--------------------------- |
| **Evaluación de condición** | Al inicio (antes de iterar)     | Al final (después de iterar) |
| **Ejecución mínima**        | 0 veces (si es falsa de inicio) | 1 vez garantizada            |

---

## 12.3. Ejemplos de Uso

A) Ejecución con Condición Falsa desde el Inicio

```php
<?php
$i = 10;

// Aunque $i no es menor que 5, el bloque se ejecuta una vez
do {
    echo "Se ejecuta al menos una vez. Valor de \$i: $i\n";
    $i++;
} while ($i < 5);
?>
```

B) Conteo Ascendente Estándar

```php
<?php
$contador = 1;

do {
    echo "Número: $contador\n";
    $contador++;
} while ($contador <= 5);
?>
```

C) Evaluación de Condición Variable

```php
<?php
$opcion = 0;

do {
    echo "Procesando solicitud (Opción seleccionada: $opcion)...\n";
    $opcion++; // Incremento simulado de opción de salida
} while ($opcion < 3);
?>
```

---

## 12.4. Control del Bucle: _break_ y _continue_

- _break_: Finaliza la ejecución del bucle de forma anticipada.
- _continue_: Salta el resto del código actual y pasa directamente a evaluar la condición del `-while`.

```php
<?php
$i = 1;

do {
    if ($i === 3) {
        $i++;
        continue; // Salta la iteración cuando $i es 3
    }

    if ($i === 13) {
        break; // Cancela la ejecución cuando $i llega a 13
    }

    echo "Valor de \$i: $i\n";
    $i++;
} while ($i <= 20);
?>
```
