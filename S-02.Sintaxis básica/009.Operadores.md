# 9. OPERADORES EN PHP

En programación, un **operador** es un símbolo o palabra clave que le indica al motor del lenguaje (en este caso, PHP) que debe realizar una acción específica (operación) sobre uno o más valores (operandos).

---

## 9.1. Clasificación según el número de operandos

Es la clasificación técnica según cuántos valores requiere el operador para funcionar:

### A) Unarios

Necesitan **un solo operando**.

- `!$boolean`: Operador lógico NOT (invierte el booleano).
- `$numero++`: Postincremento (incrementa en 1 tras evaluar la expresión).
- `++$numero`: Preincremento (incrementa en 1 antes de evaluar la expresión).
- `$objeto->propiedad`: Acceso directo (requiere que el objeto exista o arroja error fatal).
- `$objeto?->propiedad`: Acceso seguro _Nullsafe_ (devuelve `null` si el objeto no existe, evitando errores fatales).
- `&$variable`: Referencia (obtiene/asigna la dirección de memoria de la variable).

### B) Binarios

Necesitan **dos operandos** (son los más comunes).

- `$a + $b`: TODOS los operadores aritméticos como suma, resta, multiplicación, división, módulo y potencia (+, -, \*, /, %, \*\*).
- `$x = $y`: TODOS los operadores de asignación (=, +=, -=, \*=, /=, .=).
- `$cadena == $numero`: Igualdad laxa (realiza conversión implícita de tipos).
- `$x === $y`: Igualdad estricta (mismo valor y mismo tipo de dato).
- `$nombre . $apellido`: Operador de concatenación de strings.
- `$a && $b`: Operador lógico AND.
- `$a || $b`: Operador lógico OR.
- `$nombreUsuario = $nombreRegistrado ?? "Invitado"`: Operador de coalescencia nula.
- `Clase::metodo()`: Operador de resolución de ámbito (miembros estáticos/constantes).

### C) Ternarios

Necesitan **tres operandos**. En PHP únicamente existe el **operador condicional (`?  :`)**:

- `$edad > 18 ? "Adulto" : "Niño"`

## 9.2. Operadores de Selección y Condicionales

### 9.2.1 Operador Condicional Ternario (`?  :`)

Es la forma abreviada de una estructura `if-else`.

**Sintaxis:**

```php
<?php
$resultado = (condicion) ? $valor_Si_condicion_es_true : $valor_Si_condicion_es_false;
?>
```

Por ejemplo:

```php
<?php
$edad = 20; // Modifica el valor de la edad para ver otro funcionamiento.

// Si $edad >= 18 es true devuelve "Adulto", de lo contrario "Niño"
$etapa = ($edad >= 18) ? "Adulto" : "Niño";

echo "Por tu edad de $edad años eres $etapa \n\n";
?>
```

### 9.2.2 Operador "Short Ternary" (`?:`)

Evalúa si la primera expresión es truty (verdadera en contexto booleano). Si es verdadera, devuelve su propio valor; si es falsy (_0_, _"0"_, _0.0_, _""_, _[]_, _NULL_), devuelve el segundo valor. Aunque omite la parte central de la evaluación. NO SE RECOMIENDA SU USO.

**Sintaxis:**

```php
<?php
$resultado = $valor_evaluado_y_asignado_Si_es_true ?: $valor_asignado_Si_es_false;
?>
```

Por ejemplo:

```php
<?php
$nombreRegistrado = ""; // Modifica el valor. En PHP, son valores 'falsy': 0, "0", 0.0, "", [], NULL.

// Si $nombreRegistrado se evalúa como false, se asigna "Invitado" a la variable $nombreUsuario.
// Si $nombreRegistrado se evalúa como true, se asigna el valor de $nombreRegistrado a $nombreUsuario
$nombreUsuario = $nombreRegistrado ?: "Invitado";    // Modifica el nombre de la variable para que sea variable NO definida

echo "El nombre registrado es '$nombreRegistrado' por lo que tu nombre de usuario es: '$nombreUsuario'\n\n";

// CUIDADO: Si la variable no está definida:
// echo $variableNoExiste ?: "Default";
// Genera: Warning: Undefined variable $variableNoExiste
?>
```

**Problemas del Short Ternary:**

1. **Notice / Warning**: Si la variable no existe, genera un aviso de variable indefinida (Warning: Undefined variable $variableNoExiste).
2. **Evaluación de Falsy**: Salta al segundo valor si la variable contiene valores válidos que evalúan a _false_ en PHP (_0_, _"0"_, _0.0_, _""_, _[]_, _NULL_).

### 9.2.3 Operador de Coalescencia Nula (`??`)

Diseñado para manejar variables que podrían no estar definidas o ser null. Devuelve el primer valor si existe y no es null, aunque sea un valor "falsy" como _0_, _"0"_, _0.0_, _""_, _[]_.

**Sintaxis:**

```php
<?php
$resultado = $valor_Si_existe_y_no_es_NULL ?? $valor_predeterminado;
?>
```

Por ejemplo:

```php
<?php
$nombreRegistrado = ""; // Modifica el valor. En PHP, son valores 'falsy': 0, "0", 0.0, "", [], NULL.

$nombreUsuario = $nombreRegistrado ?? "Invitado";

echo "El nombre registrado es '$nombreRegistrado' por lo que tu nombre de usuario es: '$nombreUsuario'";

// Ejemplo 2: Variable no definida o nula
$avatar = $_GET['avatar'] ?? "default.png";
echo $avatar; // Resultado: "default.png" (No genera Warning si $_GET['avatar'] no existe)
?>
```

### 9.2.4 Asignación de Coalescencia Nula (??=) (PHP 7.4+)

Simplifica la inicialización de variables. Es una versión resumida del Operador de Coalescencia Nula (`??`). Asigna el valor de la derecha a la variable de la izquierda únicamente si la variable de la izquierda es null o no está definida.

Es decir, en vez de escribir:

```php
<?php
$valor_Si_existe_y_no_es_NULL = $valor_Si_existe_y_no_es_NULL ?? valor_predeterminado;
?>
```

Se escribe:

```php
<?php
$valor_Si_existe_y_no_es_NULL ??= valor_predeterminado;
?>
```

Por ejemplo:

```php
<?php
$nombreRegistrado = ""; // Modifica el valor.

$nombreRegistrado ??= "Invitado";   // Equivale a escribir: $nombreRegistrado = $nombreRegistrado ?? "Invitado";

echo "El nombre final del usuario es: '$nombreRegistrado'\n\n";
?>
```

Otro ejemplo, porque ya fue mucho nombre...

```php
<?php
$puerto = 8080;     // Modifica el valor del puerto
$puerto ??= 3000;   // Como $puerto ya existe y no es null, se conserva 8080.

echo "Se usará el puerto: $puerto \n\n"; // Resultado: 8080
?>
```

## 9.3. Catálogo general de operadores comunes en PHP

| Categoría                 | Operadores                                            | Descripción / Ejemplo                                            |
| :------------------------ | :---------------------------------------------------- | :--------------------------------------------------------------- |
| **Aritméticos**           | `+`, `-`, `*`, `/`, `%`, `**`                         | Operaciones matemáticas (módulo `%`, exponenciación `**`).       |
| **Asignación**            | `=`, `+=`, `-=`, `*=`, `/=`, `.=`                     | Asignan y combinan operaciones (`$a .= " text"` concatena).      |
| **Comparación**           | `==`, `===`, `!=`, `!==`, `<`, `>`, `<=`, `>=`, `<=>` | Comparan valores. `<=>` (Spaceship) devuelve -1, 0 o 1.          |
| **Lógicos**               | `&&`, `\|\|`, `!`, `and`, `or`, `xor`                 | Evaluación booleana (`xor` es verdadero si solo uno es true).    |
| **Incremento/Decremento** | `++$a`, `$a++`, `--$a`, `$a--`                        | Pre/Post incremento y decremento.                                |
| **Strings**               | `.`, `.=`                                             | Concatenación de cadenas de texto.                               |
| **Arrays**                | `+`, `==`, `===`, `!=`, `<>`                          | Unión de arrays (`+`), comparación e identidad de arrays.        |
| **Nulabilidad y Objetos** | `??`, `??=`, `?->`, `->`, `::`                        | Coalescencia, acceso seguro, acceso a objetos y ámbito estático. |

## 9.4. Operadores destacados

### 9.4.1 Operador Nave Espacial (`<=>`) [PHP 7+]

El Operador Nave Espacial (`<=>`) compara dos datos y da un número según el resultado:

- Devuelve -1 si el de la izquierda es menor.
- Devuelve 0 si ambos son iguales.
- Devuelve 1 si el de la izquierda es mayor.

**Sintaxis:**

```php
<?php
$resultado = $valor_izquierda <=> $valor_derecha;
?>
```

Por ejemplo:

```php
<?php
echo "a) Operador Nave Espacial (<=>) [PHP 7+]:\n";
echo "   - Al evaluar (1 <=> 2) se devuelve el valor: " . (1 <=> 2) . " (Devuelve -1 si el de la izquierda es menor y el de la derecha es mayor)\n";
echo "   - Al evaluar (2 <=> 2) se devuelve el valor: " . (2 <=> 2) . " (Devuelve 0 si son iguales los valores)\n";
echo "   - Al evaluar (3 <=> 2) se devuelve el valor: " . (3 <=> 2) . " (Devuelve 1 si el de la izquierda es mayor y el de la derecha es menor)\n\n";
?>
```
