# 14. FUNCIONES PREEXISTENTES (NATIVAS) EN PHP

Las **funciones preexistentes o nativas** son aquellas integradas directamente en el núcleo del lenguaje PHP. Permiten resolver tareas comunes de manipulación de datos, operaciones matemáticas, manejo de fechas, gestión de archivos y consumo de estructuras complejas sin necesidad de escribir lógica desde cero.

---

## 14.1. Principales Categorías de Funciones Nativas

### 1. Funciones de Cadena (Strings)

- `strlen(string $cadena): int`: Devuelve la longitud de una cadena.
- `strtoupper(string $cadena): string`: Convierte el texto a mayúsculas.
- `strtolower(string $cadena): string`: Convierte el texto a minúsculas.
- `strpos(string $cadena, string $subcadena): int|false`: Busca la posición de la primera aparición de una subcadena.
- `substr(string $cadena, int $inicio, ?int $longitud): string`: Extrae una porción del texto.
- `trim(string $cadena): string`: Elimina espacios en blanco al inicio y al final.
- `ucwords(string $cadena): string`: Convierte a mayúscula el primer carácter de cada palabra.

### 2. Funciones Matemáticas

- `abs(int|float $numero): int|float`: Devuelve el valor absoluto.
- `round(float $numero, int $precision = 0): float`: Redondea al entero o decimal más cercano.
- `ceil(float $numero): float`: Redondea hacia arriba al entero más cercano.
- `floor(float $numero): float`: Redondea hacia abajo al entero más cercano.
- `rand(int $min, int $max): int`: Genera un entero aleatorio inclusivo.
- `sqrt(float $numero): float`: Devuelve la raíz cuadrada.
- `pow(float $base, float $exponente): float`: Eleva una base a una potencia.

### 3. Funciones de Fecha y Hora

- `date(string $formato, ?int $timestamp = null): string`: Formatea una fecha/hora local.
- `time(): int`: Devuelve la marca de tiempo Unix actual (_timestamp_).
- `strtotime(string $fecha): int|false`: Convierte una descripción de texto en formato fecha a _timestamp_.
- `mktime(int $hora, int $minuto, int $segundo, int $mes, int $dia, int $año): int|false`: Obtiene el _timestamp_ para una fecha específica.

### 4. Funciones del Sistema de Archivos (Filesystem)

- `fopen(string $archivo, string $modo)`: Abre un archivo o URL y devuelve un recurso (_stream_).
- `fclose(resource $puntero): bool`: Cierra un puntero a un archivo abierto.
- `fread(resource $puntero, int $longitud): string|false`: Lee bytes de un archivo abierto.
- `fwrite(resource $puntero, string $contenido): int|false`: Escribe datos en un archivo abierto.
- `fgets(resource $puntero): string|false`: Lee una línea entera desde un archivo.
- `feof(resource $puntero): bool`: Comprueba si el puntero está al final del archivo (EOF).
- `copy(string $origen, string $destino): bool`: Copia un archivo.
- `unlink(string $archivo): bool`: Elimina un archivo del sistema.
- `rename(string $origen, string $destino): bool`: Renombra o mueve un archivo.

### 5. Funciones de Arreglos (Arrays)

- `count(Countable|array $array): int`: Cuenta todos los elementos de un arreglo.
- `in_array(mixed $aguja, array $pajar, bool $estricto = false): bool`: Comprueba si un valor existe en un arreglo.
- `array_key_exists(string|int $clave, array $array): bool`: Verifica si existe una clave determinada en el arreglo.
- `array_merge(array ...$arrays): array`: Combina uno o más arreglos.
- `array_map(?callable $callback, array $array1): array`: Aplica una función a cada elemento de un arreglo.
- `array_filter(array $array, ?callable $callback = null): array`: Filtra elementos utilizando una función de callback.

### 6. Funciones de Formato JSON (APIs)

- `json_encode(mixed $valor, int $flags = 0): string|false`: Convierte una estructura de datos de PHP a un string JSON.
- `json_decode(string $json, ?bool $associative = null): mixed`: Convierte un string JSON a un objeto o arreglo asociativo de PHP.

### 7. Inspección de Tipos

- `isset(mixed $var, mixed ...$vars): bool`: Determina si una variable está definida y no es `null`.
- `empty(mixed $var): bool`: Determina si una variable se considera vacía (`""`, `0`, `null`, `false`, `[]`).
- `var_dump(mixed $value, mixed ...$values): void`: Muestra información detallada sobre una o más variables (esencial para depuración).

### 8. Criptografía

- `password_hash(string $password, string|int|null $algo): string`: Crea un hash seguro de contraseña.
- `password_verify(string $password, string $hash): bool`: Comprueba si una contraseña coincide con un hash guardado.

## 14.2. Nota sobre Librerías y Extensiones (Ejemplo: cURL -Véase más a fondo en S-014.Bibliotecas-)

No todas las funciones disponibles corresponden al núcleo básico del lenguaje. Algunas herramientas clave en PHP, como **cURL**, son **extensiones cliente (_libcurl_)** diseñadas para transferir datos e interactuar con APIs externas mediante su propio conjunto de funciones nativas (`curl_init()`, `curl_setopt()`, `curl_exec()`, `curl_close()`):

```php
<?php
// Ejemplo básico de petición HTTP usando la extensión cURL
$ch = curl_init("[https://api.ejemplo.com/datos](https://api.ejemplo.com/datos)");
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$respuesta = curl_exec($ch);
curl_close($ch);
?>
```
