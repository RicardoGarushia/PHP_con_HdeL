# 11. BUCLE `WHILE` EN PHP

El **bucle `while`** es una estructura de control repetitiva (iterativa) que ejecuta un bloque de código **mientras una condición especificada se evalúe como `true`**. Se utiliza principalmente cuando **NO se conoce con certeza cuántas veces** se repetirá la ejecución.

---

## 11.1. Sintaxis Básica del Bucle `while`

En el bucle `while`, la condición se evalúa **antes** de ingresar o ejecutar cada iteración.

```php
<?php
while (condicion) {
    // Código a ejecutar mientras la condición sea verdadera
}
?>
```

- **Condición**: Si es _true_, entra al bucle y ejecuta el código. Si es _false_, salta el bucle y continúa con la ejecución del script.
- **Modificación de la condición**: Dentro del bucle debe existir un mecanismo (como un incremento/decremento) que eventualmente haga que la condición sea _false_. De lo contrario, se genera un bucle infinito.

---

## 11.2. Ejemplos de Uso

A) Contador Ascendente Estándar

```php
<?php
$i = 1;

// Imprime números del 1 al 5
while ($i <= 5) {
    echo "Iteración número: $i\n";
    $i++; // Incremento obligatorio para evitar bucle infinito
}
?>
```

B) Conteo Descendente

```php
<?php
$contador = 5;

while ($contador >= 1) {
    echo "Cuenta regresiva: $contador\n";
    $contador--;
}
?>
```

C) Evaluación de Condición Variable

```php
<?php
$continuar = true;
$intentos = 1;

while ($continuar) {
    echo "Intento número: $intentos\n";

    // Primero se realiza la evaluación de la variable
    if ($intentos === 13) {
        $continuar = false; // Modifica la condición para detener el bucle
    }

    // Después se hace incremento de la variable
    $intentos++;
}
?>
```

---

## 11.3. Control del Bucle: _break_ y _continue_

- _break_: Rompe la ejecución del bucle inmediatamente.
- _continue_: Salta el resto del código en la iteración actual y pasa inmediatamente a evaluar la condición para la siguiente iteración.

```php
<?php
$i = 0;

while ($i < 20) {
    $i++;

    if ($i === 3) {
        continue; // Salta la iteración cuando $i es 3
    }

    if ($i === 13) {
        break; // Detiene el bucle por completo al llegar a 13
    }

    echo "Valor de \$i: $i\n";
}
?>
```
