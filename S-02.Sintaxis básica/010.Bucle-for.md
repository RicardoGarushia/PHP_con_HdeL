# 10. BUCLE `FOR` EN PHP

El **bucle `for`** es una estructura de control repetitiva (iterativa) que se utiliza cuando **se conoce de antemano el número exacto de veces** que se debe ejecutar un bloque de código.

---

## 10.1. Sintaxis Básica del Bucle `for`

El **bucle `for`** agrupa el valor de inicialización, la condición de parada y el incremento/decremento en una sola línea de encabezado:

```php
<?php
for (inicialización; condición; incremento/decremento) {
    // Código a ejecutar en cada iteración
}
?>
```

- **Inicialización**: Se ejecuta una sola vez al inicio (ej. $i = 1).
- **Condición**: Se evalúa antes de cada iteración. Si es true, ejecuta el bloque de código; si es false, el bucle termina.
- **Incremento/Decremento**: Se ejecuta al final de cada iteración para modificar el contador (ej. $i++).

---

## 10.2. Ejemplos de Uso

A) Contador Ascendente Estándar

```php
<?php
// Imprime números del 1 al 5
for ($i = 1; $i <= 5; $i++) {
    echo "Iteración número: $i\n";
}
?>
```

B) Conteo Descendente

```php
<?php
// Cuenta regresiva del 5 al 1
for ($i = 5; $i >= 1; $i--) {
    echo "Cuenta regresiva: $i\n";
}
?>
```

C) Saltos (Incrementos/Decrementos Personalizados)

```php
<?php
// Imprime números pares de 0 a 10
for ($i = 0; $i <= 10; $i += 2) {
    echo "Número par: $i\n";
}
?>
```

---

## 10.3. Control del Bucle: _break_ y _continue_

- _break_: Interrumpe y sale del bucle de forma inmediata.
- _continue_: Salta el resto de la iteración actual y pasa directamente a la siguiente.

```php
<?php
for ($i = 1; $i <= 20; $i++) {
    if ($i === 3) {
        continue; // Salta la iteración cuando $i es 3
    }
    if ($i === 13) {
        break; // Detiene el bucle por completo al llegar a 13
    }
    echo "Valor de \$i: $i\n";
}
?>
```
