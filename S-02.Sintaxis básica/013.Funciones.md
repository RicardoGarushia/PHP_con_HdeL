# 13. FUNCIONES EN PHP

Una **función** es un bloque de código reutilizable diseñado para realizar una tarea específica. Permiten modularizar el programa, evitar la duplicación de código (_DRY - Don't Repeat Yourself_), facilitar la depuración y mejorar la legibilidad.

---

## 13.1. Sintaxis General y Tipado

Desde PHP 7+ es posible declarar explícitamente el tipo de dato de los parámetros y el tipo de dato del valor de retorno.

```php
<?php
function nombreFuncion(tipoDato $parametroA, tipoDato $parametroB): tipoDatoRetorno {
    // Cuerpo de la función
    return $valor; // Opcional
}
?>
```

- **Nombre**: Debe seguir las reglas de identificadores en PHP (letras, números o guion bajo; no puede empezar con número).
- **Parámetros ($parametro)**: Datos de entrada opcionales.
- **Tipo de Retorno (: tipoRetorno)**: Define qué tipo de dato devolverá (int, string, array, void, etc.). Si se usa void, la función no debe devolver ningún valor.

---

## 13.2. Combinaciones de Parámetros y Retorno

A) Sin Parámetros y Sin Retorno (void)

```php
<?php
function saludar1(): void {
    echo "¡Hola desde la función saludar1()!\n";
}

saludar1();
?>
```

B) Sin Parámetros y Con Retorno

```php
<?php
function saludar2(): string {
    return "¡Hola desde la función saludar2()!\n";
}

$mensaje = saludar2();
echo $mensaje;
?>
```

C) Con Parámetros y Sin Retorno (void)

```php
<?php
function saludar3(string $nombre, string$apellido): void {
    echo "¡Hola, $nombre$apellido!\n";
}

saludar3("Ricardo", "García");
?>
```

D) Con Parámetros y Con Retorno

```php
<?php
function saludar4(string $nombre, string$apellido): string {
    return "¡Hola, $nombre$apellido!\n";
}

$saludo = saludar4("Ricardo", "García");
echo $saludo;
?>
```

---

## 13.3. Parámetros Opcionales y Valores por Defecto

Permiten asignar un valor predeterminado a un parámetro si este no se envía al momento de la invocación.
**Regla importante**: Los parámetros opcionales siempre deben colocarse al final de la lista de parámetros.

```php
<?php
function saludar5(string $nombre = "Invitado"): string {
    return "¡Hola, $nombre!\n";
}

echo saludar5();        // Imprime: ¡Hola, Invitado!
echo saludar5("Juan");  // Imprime: ¡Hola, Juan!
?>
```

## 13.4. (REPASO DE 5.3.1) Tipos Nullables y Tipos de Unión (Nullable & Union Types)

- **Nullable (_?Tipo_)**: Permite que el parámetro o valor de retorno sea del tipo indicado o null.
- **Union Types (_TipoA|TipoB_ - PHP 8+)**: Permite especificar múltiples tipos válidos.

```php
<?php
$id = null; // Modifica el valor

// Retorna string o null
function buscarUsuario(?string $id): ?string {
    if ($id === null) {
        return null;
    }
    return "Usuario con ID: $id";
}

$resultado = buscarUsuario($id);
echo $resultado === null ? "No se encontró usuario\n" : $resultado;
?>
```

## 13.5. Tipos Específicos de Funciones (Véase en 5.3.1 Modificadores de Declaración de Tipo (Nullable y Union Types))

### 13.5.1. Funciones Recursivas

Una **función recursiva** es una función que se llama a sí misma para resolver un problema dividiéndolo en casos más pequeños. Requiere siempre un caso base para detener las llamadas.

```php
<?php
function factorial(int $n): int {
    if ($n <= 1) {
        return 1; // Caso base
    }
    return $n * factorial($n - 1);  // Llamada recursiva
}

echo "El factorial de 5 es: " . factorial(5) . "\n";
?>
```

### 13.5.2. Funciones Anidadas

Las **funciones anidadas** implican la invocación de una función dentro del cuerpo de otra para descomponer la lógica.

```php
<?php
function multiplicar(float $a, float$b): float {
    return $a * $b;
}

function calcularArea(float $base, float$altura): float {
    return multiplicar($base,$altura);  // Función multiplicar() anidada
}

echo calcularArea(5, 10); // 50
?>
```

### 13.5.3. Funciones Anónimas (Closures)

Las **funciones anónimas (closures)** son funciones sin nombre asignadas a variables. Se invocan usando el nombre de la variable.

```php
<?php
$suma = function(int $a, int$b): int {
    return $a +$b;
};

echo $suma(5, 10); // 15
?>
```

A) Recursividad en Funciones Anónimas

Para que una función anónima se llame a sí misma, se debe importar su propia variable mediante referencia (_use (&$variable)_).

```php
<?php
$factorial = function(int $n) use (&$factorial): int {
    if ($n <= 1) {
        return 1;
    }
    return $n * $factorial($n - 1);
};

echo $factorial(5); // 120
?>
```

### 13.5.4. Funciones Flecha (Arrow Functions)

Introducidas en PHP 7.4 (_fn()_), son una sintaxis concisa para funciones anónimas de una sola expresión. Capturan variables del ámbito externo de forma automática por valor.

```php
<?php
$duplicar = fn(int $n): int =>$n * 2;

echo $duplicar(8); // 16
?>
```
