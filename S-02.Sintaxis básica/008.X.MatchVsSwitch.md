# 8.X. EXPRESIÓN `MATCH` EN PHP (PHP 8.0+)

Introducida en PHP 8.0, la **EXPRESIÓN `match`** es una alternativa moderna, más segura y concisa a la **estructura de control `switch`**. Al igual que `switch`, permite evaluar una expresión contra múltiples casos, pero con mejoras significativas en rendimiento y sintaxis.

Para empezar, una **expresión** es cualquier pedazo de código que el intérprete de PHP calcula y reduce a un único valor final (como una función, un operador matemático, el operador ternario o match). Por eso puedes asignarla a una variable, pasarla como argumento a una función o retornarla. Mientras que una **estructura de control** es una orden/instrucción para el programa. Controla qué se ejecuta, cuántas veces o en qué orden, pero el bloque en sí mismo no equivale a ningún dato. No puedes guardarlo dentro de una variable.

---

## 8.X.1. Diferencias Clave: `match` vs. `switch`

| Característica               | `switch`                                                     | `match`                                                                     |
| :--------------------------- | :----------------------------------------------------------- | :-------------------------------------------------------------------------- |
| **Tipo de Comparación**      | Débil (`==`) con conversión implícita.                       | **Estricta (`===`)** sin conversión de tipos.                               |
| **Retorno de Valor**         | Es una estructura de control (no devuelve ningún valor).     | **Es una expresión** (Devuelve un valor y se puede asignar a una variable). |
| **Control de Flujo**         | Requiere `break` para evitar el _fall-through_.              | **No requiere `break`** (ejecuta solo el caso coincidente).                 |
| **Manejo de Casos No Found** | Si no coincide y no hay `default`, continúa silenciosamente. | Lanza una excepción `UnhandledMatchError` si no hay `default`.              |

---

## 8.X.2. Sintaxis Básica

```php
<?php
$resultado = match ($variable) {
    $valorA => "Resultado A",
    $valorB => "Resultado B",
    $valorC, $valorD => "Resultado C o D", // Agrupamiento con comas
    default => "Resultado por defecto",
};
?>
```

_Nota de Sintaxis_: A diferencia de la estructura de control `switch`, la **expresión `match`** debe finalizar con un punto y coma ; al cerrar la llave _$resultado = match (...) { ... };_.

## 8.X.3. Ejemplo Práctico: Evaluación Estricta de Tipo de Dato

Un error común en la estructura de control `switch` es que la cadena "1" equivale al entero 1 debido a la comparación débil (==). La **expresión `match`** resuelve esto mediante la comparación estricta (===):

```php
<?php
// La expresión match mediante la comparación estricta (===) también evalúa de forma estricta el Tipo de Dato de la variable.
$opcion = 1; // Modifica este valor a tipo int o string para ver el funcionamiento

$mensaje = match ($opcion) {
    "1"     => "Para la expresión match esto es un string \"1\" \n", // No coincidirá
    1       => "Para la expresión match esto es un entero 1 \n",   // Coincidencia exacta
    default => "Opción no válida \n",
};

echo $mensaje . "\n\n"; // Imprime el mensaje dependiendo del tipo de dato

// Un error común en la estructura de control switch es que la cadena "1" equivale al entero 1 debido a la comparación débil (==).
switch ($opcion) {
    case "1":
        $mensaje = "Para la estructura switch esto es un string \"1\" \n";
        break;
    case 1:
        $mensaje = "Para la estructura switch esto es un entero 1 \n";
        break;
    default:
        $mensaje = "Opción no válida\n";
        break;
}

echo $mensaje . "\n\n"; // Imprime el mensaje del primer valor aunque sea entero por la comparación débil (==)
?>
```

### 8.X.4. Ejemplo Práctico: Agrupamiento de Casos (Case Stacking)

Es posible agrupar múltiples cláusulas case consecutivas para ejecutar una misma acción cuando compartan la misma respuesta o categoría (por ejemplo, agrupar meses para determinar las estaciones del año).

```php
<?php
$mes = 7;   // 1 == enero, 2 == febrero, 3 == marzo, y así sucesivamente.

// Asignación directa del resultado de match a una variable
$estacion = match ($mes) {
    12, 1, 2  => "Invierno",
    3, 4, 5   => "Primavera",
    6, 7, 8   => "Verano",
    9, 10, 11 => "Otoño",
    default   => "Mes no válido",
};

echo "Evaluando el mes número $mes:\n";
echo "Estación detectada: $estacion\n\n";
?>
```

---

### 8.X.5. Resumen y Regla de Oro

- Usa la **expresión `match`** (PHP 8+): Cuando quieras comparar el valor exacto de una sola variable frente a opciones fijas y necesites retornar un valor directamente. Es la opción preferida en PHP moderno porque realiza comparaciones estrictas (`===`), no sufre de caídas de casos accidentales por olvidar un `break`, obliga a manejar todos los casos posibles (o usar `default`) y permite sintaxis limpia de una sola línea por brazo.
- Usa la **estructura de control `switch`**: Cuando tengas una sola variable y quieras evaluar coincidencia estática, pero necesites ejecutar bloques de código multilínea complejos dentro de cada caso, o cuando intencionalmente requieras la caída de casos (fall-through) ejecutando un `case` tras otro sin colocar un `break`.
- Usa la **estructura de control `if - elseif - else`**: Cuando necesites evaluar rangos o comparaciones desiguales (`$edad >= 18`), múltiples variables a la vez, o condiciones complejas con operadores lógicos (`&&, ||`).
