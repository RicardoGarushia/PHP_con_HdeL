# 13.X. PASAR POR VALOR VS. PASAR POR REFERENCIA EN PHP

## 13.X.1. Ámbito de Ejecución (Scope) y Parámetros

Cuando PHP invoca una función, crea un **nuevo ámbito de ejecución (scope local)**.

Por defecto, las variables pasadas como parámetros se asignan a ese ámbito local. Cualquier modificación dentro de la función **no afecta** a las variables del ámbito global a menos que:

1. Se use la sentencia `return` para reasignar el resultado explícitamente.
2. Se utilice el **paso por referencia** mediante el operador de dirección de memoria (`&`).

---

## 13.X.2. Comparativa: Pasar Por Valor vs. Pasar Por Referencia

- **Paso por Valor (Por Defecto):** Se pasa una **copia del valor de la variable** al parámetro de la función. La variable original permanece intacta fuera del scope de la función.
- **Paso por Referencia (`&`):** Se pasa la **referencia directa en memoria de la variable**. Cualquier modificación sobre el parámetro afecta inmediatamente a la variable original fuera de la función.

| Criterio                | Pasar por Valor (Por Defecto)            | Pasar por Referencia (&)                                                                        |
| :---------------------- | :--------------------------------------- | :---------------------------------------------------------------------------------------------- |
| **Comportamiento**      | Recibe una copia del dato.               | Recibe un puntero/dirección a la variable original.                                             |
| **Efectos Secundarios** | Ninguno. La variable original no cambia. | Sí. La variable original cambia fuera de la función.                                            |
| **Cuándo Usar**         | Para el 90%-95% de los casos generales.  | Modificación directa de arreglos/estructuras pesadas, múltiples salidas o patrones específicos. |
| **Transparencia**       | Alta. Explícito mediante return.         | Baja. Modifica el estado de variables "a espaldas" del llamador.                                |

---

## 13.X.3. Sintaxis y Tipado Estricto

El operador ampersand (`&`) se antepone al nombre del parámetro en la firma de la función, incluso si se especifica el tipo de dato. Para un ejemplo práctico tenemos:

```php
<?php
$valorA = 10;
$valorB = 10;

// Paso por valor
function sumar10PorValor(int $valorA): void {
    $valorA += 10; // Modifica la copia local
}

// Paso por referencia
function sumar10PorReferencia(int &$valorB): void {
    $valorB += 10; // Modifica la dirección de memoria original
}

echo "\nValor inicial de \$valorA = $valorA \n\n";
echo "\nValor inicial de \$valorB = $valorB \n\n";
sumar10PorValor($valorA);
echo "Tras llamar a sumar10PorValor(), \$valorA sigue siendo = $valorA\n\n";

sumar10PorReferencia($valorB);
echo "Tras llamar a sumar10PorReferencia(), \$valorB ahora es = $valorB\n\n";
?>
```

---

## 13.X.4. Comportamiento Especial con Arreglos (Arrays) (véase Sección 03.Arrays)

A diferencia de lenguajes como JavaScript o Python donde los objetos/arreglos se pasan por referencia implícita, en PHP los arreglos se pasan por valor (copia) por defecto (Copy-on-Write). Si deseas modificar un arreglo dentro de una función sin retornarlo, debes usar paso por referencia.

```php
<?php
function agregarElemento(array &$lista, string $elemento): void {
    $lista[] = $elemento; // Modifica directamente el array original
}
?>
```
