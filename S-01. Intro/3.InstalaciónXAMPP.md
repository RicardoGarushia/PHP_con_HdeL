# 3. GUÍA COMPLETA DE INSTALACIÓN, INFRAESTRUCTURA Y VERIFICACIÓN DE XAMPP / PHP

## 3.1. Infraestructura y Configuración del Entorno

Para desarrollar aplicaciones en PHP es fundamental comprender la arquitectura cliente-servidor. El entorno local de desarrollo requiere:

- **Servidor Web:** Procesa las peticiones HTTP (ej. Apache, Nginx).
- **Intérprete de PHP:** Motor que ejecuta el código PHP del lado del servidor.
- **SGBD (Sistema de Gestión de Bases de Datos):** Para la persistencia de datos (ej. MySQL, MariaDB, PostgreSQL).
- **Editor / IDE:** Herramienta para escritura y depuración de código.
- **Navegador Web:** Cliente que solicita y renderiza el resultado retornado por los scripts PHP.

---

## 3.2. Stacks de Desarrollo (Paquetes Todo-en-Uno)

Existen distribuciones integradas que instalan y configuran el entorno con pocos clics:

- **XAMPP:** Multiplataforma. El estándar más extendido. Incluye Apache, MariaDB, PHP y Perl.
- **LAMP:** Linux, Apache, MySQL/MariaDB, PHP. Típico de servidores Linux y producción.
- **Laragon:** Exclusivo de Windows. Ligero, portable y con gestión automática de _Virtual Hosts_.
- **MAMP:** Diseñado originalmente para macOS (ahora también en Windows). Muy intuitivo.
- **EasyPHP:** Exclusivo para Windows. Entorno sencillo para pruebas rápidas.
- **Docker (Avanzado):** Permite aislar componentes en contenedores, replicando entornos de producción exactos.

En nuestro caso, usaremos XAMPP por los siguientes puntos clave según la documentación oficial y portales técnicos:

- **Unificación de Servicios:** Integra el servidor web Apache, la base de datos MariaDB y los lenguajes PHP y Perl sin requerir configuraciones complejas por separado. Está concebida principalmente como un entorno de desarrollo local sin lidiar con la configuración individual de cada servicio.
- **Compatibilidad:** Depende de las librerías _Visual C++ Redistributable_ en sistemas Windows para que el ejecutable de PHP reconozca el entorno del servidor.
- **Control Visual:** Su _Control Panel_ permite iniciar y detener los servicios de Apache y base de datos con un solo clic.
- **Consideraciones de Red:** Durante la instalación, debe asegurarse de que los puertos predeterminados (`80` para HTTP y `3306` para MySQL) no estén bloqueados u ocupados por otras aplicaciones (como Skype o IIS).

## 3.3. Resumen de Instalación de XAMPP

Básicamente la instalación consiste en descargar el instalador de la página oficial (https://www.apachefriends.org/es/index.html) y ejecutarlo para instalar XAMPP con los demás servicios.

## 3.4. Herramientas de Codificación (IDEs vs. Editores)

- **Cursor:** Basado en la arquitectura de VS Code, es el editor enfocado en Inteligencia Artificial más utilizado en la actualidad. Integra asistentes de código nativos, autocompletado contextual profundo y capacidad de refactorizar proyectos complejos en PHP mediante comandos de lenguaje natural.
- **Visual Studio Code:** El estándar actual. Ligero y expandible mediante extensiones clave como _PHP Intelephense_ y _PHP Debug_.
- **PhpStorm:** El IDE profesional por excelencia. Ofrece análisis profundo de código y refactorización avanzada (de pago).
- **Sublime Text / Notepad++:** Editores ultraligeros ideales para modificaciones rápidas con muy bajo consumo de recursos.

> **Consejo Pro #1:** Combinar **XAMPP** con **Cursor** (o **Visual Studio Code**) representa el entorno ideal tanto para aprender PHP como para acelerar tu desarrollo con asistencia de Inteligencia Artificial.

---

## 3.5. Flujo de Trabajo Recomendado

1. **Instalación:** Instalar XAMPP o Laragon en el sistema.
2. **Directorio Raíz:** Guardar los proyectos exclusivamente dentro de `htdocs` (en XAMPP) o `www` (en Laragon).
3. **Extensión:** Nombrar los archivos con extensión `.php`.
4. **Ejecución vía Localhost:** No abrir archivos haciendo doble clic. Se debe acceder mediante la URL:
   `http://localhost/nombre_archivo.php`
   _(o `http://localhost/carpeta1/carpeta2/carpetaN/archivo.php` según corresponda)_.

> **Consejo Pro #2:** Evitar el uso de extensiones de actualización automática como _Live Server_ para archivos PHP. Acceder siempre a través de `http://localhost/` acostumbra a trabajar tal como se hace en servidores reales de producción.

## 3.6. Métodos para Verificar la Instalación de PHP

### 3.6.A. Mediante la Línea de Comandos (Terminal / PowerShell / CMD)

#### A.1 **Verificar la versión instalada: -v (número de Versión)**

```bash
    php -v
```

#### A.2 **Listar módulos y extensiones cargadas: -v (mostrar organizado en Módulos)**

```bash
    php -m
```

#### A.3 **Ejecutar/Run un script PHP rápido directamente en la consola: -r (Run/ejecutaR código PHP directamente)**

```bash
    php -r "echo 'PHP instalado correctamente\n';"
```

#### A.4 **Verificar la ruta ejecutable del interprete:**

##### A.4.1. Windows (PowerShell):

```bash
    Get-Command php
```

##### A.4.2. Linux / macOS:

```bash
    which php
```

#### A.5 **Mostrar todos los comandos de PHP disponibles: -h (Help/Ayuda para entender PHP)**

```bash
    php -h"
```

---

### 3.6.B. Utilizando un archivo PHP en el servidor web (Apache)

1. Crea un archivo llamado info.php dentro de la carpeta htdocs (C:\xampp\htdocs\info.php) con el siguiente contenido:

```php
<?php
// Muestra la configuración, directivas y extensiones activas de PHP
phpinfo();
?>
```

2. Accede desde el navegador a http://localhost/info.php.

Consejo Pro #3: Usar phpinfo() es fundamental al configurar un entorno nuevo para verificar qué versión de PHP se ejecuta y confirmar si extensiones necesarias (como pdo, mbstring o curl) están activadas.

---

### 3.6.C. Mediante el Panel de Control de XAMPP

1. Inicia el panel XAMPP Control Panel.
2. Arranca el servicio Apache (debe ponerse en verde).
3. Haz clic en el botón Admin en la fila de Apache o navega directamente a http://localhost/dashboard/.
4. Selecciona la opción PHPInfo del menú superior.
