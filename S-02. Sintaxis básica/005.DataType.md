# 5. TIPOS DE DATO BÁSICOS Y TYPE CASTING (CASTEO) EN PHP

Un **tipo de dato** (_data type_) es la clasificación de un valor que indica al intérprete de PHP qué operaciones se pueden realizar con él y cuánta memoria requiere.

---

## 5.1. Clasificación de Tipos de Datos en PHP

PHP categoriza sus tipos de datos en cuatro grandes grupos:

1. **Tipos Escalares (Primitivos):** Almacenan un único valor a la vez.
   - **`string`:** Cadenas de caracteres (ej. `"Hola Mundo"`).
   - **`int` / `integer`:** Números enteros sin decimales (ej. `42`, `-10`).
   - **`float` / `double`:** Números de punto flotante/decimales (ej. `3.1416`).
   - **`bool` / `boolean`:** Valores lógicos de verdad (`true` o `false`).
2. **Tipos Compuestos:** Pueden contener múltiples valores estructurados.
   - **`array`:** Colecciones ordenadas de pares clave-valor.
   - **`object`:** Instancias de clases.
3. **Tipos Especiales:** Representan estados o recursos externos del sistema.
   - **`null`:** Representa la ausencia explícita de valor.
   - **`resource`:** Referencias a recursos externos (conexiones a BD, archivos abiertos).
4. **Callbacks:** Representan funciones que pueden volver a llamarse.
   - **`callable` / `iterable`:** Funciones invocables o estructuras recorribles.

---

## 5.2. Funciones de Inspección: `gettype()` y `var_dump()`

Para depurar y verificar el tipo de dato de una variable, PHP proporciona dos funciones principales:

- **`gettype($var)`:** Devuelve una cadena con el nombre del tipo de dato (ej. `"string"`, `"integer"`). Es ideal para validaciones o concatenaciones en texto.
- **`var_dump($var)`:** Imprime directamente en el buffer de salida una estructura detallada que incluye el tipo, longitud y valor del dato. Es la herramienta clave para depuración (_debugging_).

```php
$nombre = "Ricardo García López";

echo gettype($nombre); // Muestra: string
var_dump($nombre);     // Muestra: string(20) "Ricardo García López"
```

## 5.3. Declaración de Tipos en Funciones y Clases (PHP 7.4+)

A partir de PHP 7.4+ y PHP 8.0+, es posible declarar explícitamente los tipos de datos en

- parámetros de funciones
- valores de retorno de funciones
- propiedades de clases
  para incrementar la robustez del código:


## 5.4. Conversión de Tipos (Type Casting)

El **Type Casting** o "casqueo" es la conversión explícita o implícita de una variable de un tipo de dato a otro.

### 5.4.1. Casting/Malabareo de Tipo Automático (Implicit Type Juggling)

PHP convierte automáticamente el tipo según el contexto de la operación:

```php
<?php
$numeroA = "10";        // Variable con el tipo de dato: string (cadena de carácteres)
$numeroB = 3.1416;      // Variable con el tipo de dato: float (número con punto flotante/decimal)
$resultado = $numeroA + $numeroB;   // Suma aritmética de una cadena más un número con número flotante.
echo "El resultado de sumar una cadena más un número con punto flotante es: $resultado" . "; que es del tipo de dato: " . gettype($resultado) . "\n\n";
?>
```

ADVERTENCIA: Aunque flexible, el **MALABARISMO DE TIPO (Type Juggling)** puede generar comportamientos inesperados en lógica crítica o transacciones financieras.

---

### 5.4.2. Casting Manual (Explicit Casting)

Se puede forzar el tipo de dato mediante dos formas:

- Mediante _Operadores de Casteo_: (int), (float), (string), (bool), (array), (object).
- Mediante _Funciones Integradas_: intval(), floatval(), strval(), boolval().

```php
<?php
$numeroA = "10";            // Variable con el tipo de dato: string (cadena de carácteres)
echo "Primero, la variable \$numeroA posee el tipo de dato: '" . gettype($numeroA) . "'\n";
$numeroA = (int)$numeroA ;   // Variable asignada con casteo manual
echo "Después, tras un Casting Manual (Explicit Casting) y reasignación, la variable \$numeroA posee el tipo de dato: '" . gettype($numeroA) . "'\n";
$numeroB = 3.1416;          // Variable con el tipo de dato: float (número con punto flotante/decimal)
$resultado = $numeroA + $numeroB;   // Suma aritmética de una cadena más un número con número flotante.
$resultado = strval($resultado);    // Conversión manual de la variable $resultado al tipo de dato string (cadena)
echo "El resultado de la suma de 10 más 3.1416 es: $resultado; que es del tipo de dato: " . gettype($resultado) . "\n\n";
?>
```
