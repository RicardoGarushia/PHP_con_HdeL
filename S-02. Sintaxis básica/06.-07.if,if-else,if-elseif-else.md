# 6. ESTRUCTURA DE CONTROL `IF`, `IF-ELSE` Y `IF-ELSEIF-ELSE` EN PHP

La **estructura de control `if`** es la sentencia condicional básica en programación. Permite alterar el flujo de ejecución evaluando si una expresión devuelve un valor booleano (`true` o `false`).

---

## 6.1. Variantes de la Estructura Condicional

1. **`if` (simple):** Ejecuta un bloque de código **únicamente si** la condición se evalúa como `true`.
2. **`if - else`:** Ofrece una vía de escape. Si la condición es `true` ejecuta el primer bloque; si es `false` ejecuta el bloque dentro del `else`.
3. **`if - elseif - else`:** Permite encadenar múltiples evaluaciones de forma secuencial. En cuanto una condición resulta verdadera, su bloque se ejecuta y el resto del encadenamiento se ignora.

---

## 6.2. Sintaxis y Bloques de Código

### 6.2.1. Sintaxis Estándar

1. **`if` (simple):**

```php
<?php
// Sintaxis condicional
if ($condicionA) {
    // Código si condiciónA es true
}
?>
```

2. **`if - else`:**

```php
<?php
// Sintaxis condicional
if ($condicionA) {
    // Código si condiciónA es true
} else {
    // Código si condiciónA es false
}
?>
```

3. **`if - elseif - else`:**

```php
<?php
// Sintaxis condicional
if ($condicionA) {
    // Código si condiciónA es true
} elseif ($condicionB){
    // Código si condiciónB es true
} elseif ($condicionC){
    // Código si condiciónC es true
} elseif ($condicionN){
    // Código si condiciónN es true
    // Continuar con tantos elseif sean necesarios
} else {
    // Código si todas las condiciones son false
}
?>
```

Nota de Sintaxis: En PHP se puede escribir tanto _elseif_ (todo junto, recomendado en sintaxis estándar) como _else if_ (separado). Ambas formas son válidas, aunque tienen ligeras diferencias si se usa sintaxis alternativa con dos puntos :.

#### 6.2.1.1. Diferencia entre Múltiples _if_ Secuenciales y _else if_

- **Múltiples if independientes:** PHP evaluará todas las condiciones una por una, pudiendo ejecutar más de un bloque si varias condiciones se cumplen.
- **Estructura if - else if - else:** PHP evalúa secuencialmente y, en cuanto encuentra la primera condición verdadera, ejecuta su bloque e ignora por completo todas las demás evaluaciones restantes.

---

## 6.3. Evaluación con Operadores Lógicos (&& y ||)

Para evaluar múltiples criterios dentro de un solo if, se utilizan operadores de combinación lógica:

- AND (&&): Exige que TODAS las expresiones evaluadas sean true.
- OR (||): Requiere que AL MENOS UNA de las expresiones sea true.

```php
<?php
$edad = 18;

if ($edad >= 18 && $edad < 65) {                                // if (condicionA AND condicionB) {
    echo "Eres un ser humano adulto en edad laboral.\n\n";      // Código si condicionA AND condicionB son true
} else if (($edad >= 0 && $edad < 18) || ($edad > 65)) {        // } else if ((condicionC) OR (condicionD)) {
    echo "Eres un ser humano que no está en edad laboral.\n\n"; // Código si condicionC OR condicionD es true
} else {                                                        // } else {
    echo "¿Qué edad es esa?\n\n";                               // Código si TODAS las condiciones PREVIAS son false
}                                                               // }
?>
```
