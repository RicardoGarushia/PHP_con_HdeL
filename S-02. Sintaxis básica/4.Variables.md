# 4. VARIABLES: EL CORAZÓN DEL MANEJO DE DATOS

En programación, una **variable** es un identificador que apunta a una ubicación en la memoria RAM.

---

## 4.1. Sintaxis e Inicialización de Variables en PHP

Para declarar e inicializar una variable en PHP se aplican las siguientes reglas:

1. **Prefijo obligatorio:** Toda variable debe comenzar con el símbolo `$`.
2. **Reglas de nombrado:** Debe iniciar con una letra o un guion bajo (`_`), nunca con un número o carácter especial. No se permiten espacios vacíos o carácteres especiales, salvo el guion bajo (`_`).
3. **Sensibilidad a mayúsculas (_Case-sensitive_):** `$variable`, `$Variable` y `$VARIABLE` representan tres variables distintas.
4. **Inicialización implícita:** A diferencia de lenguajes de tipado estático como C++ o Java, en PHP no existe la declaración de variables sin valor implícito; al asignar un valor se define y crea en memoria.

```php
<?php
// Ejemplos correctos:
$estado = null;                 // Inicialización explícita 'null'
$puntaje = 100;                 // Inicialización numérica
$nombre = "Ricardo García";     // Inicialización de string

// Ejemplos incorrectos (lanzan advertencias/errores):
$123variable = 5;   // Error sintáctico: empieza con número.    [Tienes que hacer la declaración un comentario con // para poder ejecutarlo]
$-nombre = "Juan";  // Error sintáctico: usa guion medio        [Tienes que hacer la declaración un comentario con // para poder ejecutarlo]
$variable;          // Error sintáctico: no se ha inicializado  [Tienes que hacer la declaración un comentario con // para poder ejecutarlo]
?>
```

---

### 4.1.1. Convenciones de Nombrado de Variables Recomendadas

- **Nombres descriptivos para las variables**: Utiliza nombres representativos para mejorar la mantenibilidad del código.
  Por ejemplo:
  - **camelCase**: Recomendado para variables locales y métodos (ej. $nombreUsuario).
  - **snake_case**: Frecuente en variables relacionadas con campos de bases de datos (ej. $nombre_usuario).

Siguiendo las convenciones anteriores tenemos:

```php
<?php
$nombreEstudiante = "";                     // Para utilizar localmente el nombre de un estudiante.
$edadEstudiante = 0;                        // Para utilizar localmente la edad de un estudiante.
$nombrePadreEstudiante = "";                // Para utilizar localmente el nombre del padre de un estudiante.
$nombre_estudiante = "Ricardo Leonardo";    // Para extraer/enviar/modificar el nombre de un estudiante en una base de datos.
$edad_estudiante = 35;                      // Para extraer/enviar/modificar la edad de un estudiante en una base de datos.
$nombre_padre_estudiante = "José";          // Para extraer/enviar/modificar el nombre del padre de un estudiante en una base de datos.
$variable = "01259034597";                  // MAL EJEMPLO. Denominar una variable como "variable" no dice nada sobre el contenido de esta.
?>
```

## 4.2. TIPADO DINÁMICO (Dynamic Typing), MALABARISMO DE TIPO (Type Juggling) y TIPADO ESTRICTO: declare(strict_types=1);

### 4.2.1. TIPADO DINÁMICO (Dynamic Typing)

PHP es un lenguaje de **TIPADO DINÁMICO (Dynamic Typing)**, es decir, puede cambiar de _tipo de dato_ de una variable durante la ejecución del programa.

```php
<?php
$variablE = "¡Hola!"; // Comienza con el tipo de dato: string (cadena de carácteres)
echo "\nLa variable contiene: '$variablE'; que es un tipo de dato: '" . gettype($variablE) . "'\n";
$variablE = 45;     // Cambia al tipo de dato: int (número entero)
echo "Ahora la variable contiene: '$variablE'; que es un tipo de dato: '" . gettype($variablE) . "'\n";
$variablE = true;   // Cambia al tipo de dato: boolean
echo "Enseguida la variable contiene: '$variablE'; que es un tipo de dato: '" . gettype($variablE) . "'\n";
$variablE = 3.1416; // Cambia al tipo de dato: float
echo "Después la variable contiene: '$variablE'; que es un tipo de dato: '" . gettype($variablE) . "'\n";
$variablE = null;   // Cambia al tipo de dato: null
echo "Finalmente contiene: '$variablE'; que es un tipo de dato: '" . gettype($variablE) . "'\n\n";
?>
```

---

### 4.2.2. MALABARISMO DE TIPO (Type Juggling)

PHP también es un lenguaje de **MALABARISMO DE TIPO (Type Juggling)**, es decir, automáticamente puede realizar la conversión (casting) de tipos al realizar operaciones aritméticas, comparaciones o concatenaciones, transformando el tipo de dato para que la operación tenga sentido.

```php
<?php
$numeroA = "10";        // Variable con el tipo de dato: string (cadena de carácteres)
$numeroB = 3.1416;      // Variable con el tipo de dato: float (número con punto flotante/decimal)
$resultado = $numeroA + $numeroB;   // Suma aritmética de una cadena más un número con número flotante.
echo "El resultado de sumar una cadena más un número con punto flotante es: $resultado \n\n";
?>
```

ADVERTENCIA: Aunque flexible, el **MALABARISMO DE TIPO (Type Juggling)** puede generar comportamientos inesperados en lógica crítica o transacciones financieras.

---

### 4.2.3. TIPADO ESTRICTO: declare(strict_types=1);

Para prevenir errores derivados de la flexibilidad del **TIPADO DINÁMICO (Dynamic Typing)** y del **MALABARISMO DE TIPO (Type Juggling)**, PHP permite activar la directiva de tipado estricto.

```php
<?php
declare(strict_types=1);    // Debe ser la PRIMERA instrucción del archivo

// Demás código...
?>
```

Al habilitar (strict_types=1), PHP exigirá coincidencia exacta entre los tipos esperados y recibidos en llamadas a funciones y retornos, reduciendo discrepancias en ejecución mediante errores de tipo (TypeError).

## 4.3. Clasificación de Variables e Introducción a los Tipos de Dato (data type)

De acuerdo con la documentación oficial de PHP, los _tipos de datos_ se dividen en:

- **Escalares**: bool (booleanos), int (enteros), float (números con punto flotante), string (cadenas de texto).
- **Compuestos**: array (colecciones de datos), object (instancias de clases).
- **Especiales**: resource (referencias a recursos externos como conexiones a BD o archivos), NULL (ausencia explícita de valor).
- **Pseudo-tipos / Iterables**: callable (funciones que pueden llamarse/invocarse como variables).

Y con respecto al _Ámbito de las Variables (Scope)_:

- **Locales**: Variables definidas dentro de una función o bloque, existen solo durante la ejecución de este.
- **Globales**: Variables definidas fuera de las funciones; para acceder a ellas dentro de una función se requiere la palabra reservada 'global'.

```php
<?php
// Ejemplo de variable global
$asignacionPorDiscapacidadIntelectual = 3;

// DEFINICIÓN de una función (véase 13.Funciones.md para mayor información)
function ejemploDeAmbitoGlobal()
{
    // Ejemplo de variable local
    $puntoExtra = 1;
    global $asignacionPorDiscapacidadIntelectual;     // Elimina la palabra reservada global y observa que sucede
    $resultado = $puntoExtra + $asignacionPorDiscapacidadIntelectual + 5;
    echo "El resultado es: $resultado \n\n";
}

// INVOCACIÓN de una función (véase 13.Funciones.md para mayor información)
ejemploDeAmbitoGlobal();
?>
```

- **Superglobales**: Variables predefinidas por el entorno accesibles desde cualquier punto del script (ej. $\_GET, $\_POST, $\_SESSION, $\_SERVER).

## 4.4. Funciones Guardianas: Validación de Variables

Para evitar advertencias de tipo Notice: Undefined variable, PHP incluye funciones de verificación:

- **isset($variableAEvaluar)**: Devuelve true si la variable está definida y su valor NO es _null_.
- **empty($variableAEvaluar)**: Devuelve true si la variable no existe o equivale a un valor "vacío" ("", 0, 0.0, "0", null, false, array()).

```php
<?php
$usuario = "";  // Ingresa un valor, deja el valor vacío "" y coloca el valor null para observar el comportamiento. También puedes cambiar el nombre de la variable.

// Estructura de control if-else (véase 6.if.md para mayor información)
if (isset($usuario)) {  // La función isset() responde la pregunta: ¿La variable existe (está establecida)?
    echo "La variable \$usuario existe y no es NULL\n";
} else {
    echo "La variable NO existe\n";
}

// Estructura de control if-else (véase 6.if.md para mayor información)
if (empty($usuario)) {// La función empty() responde la pregunta: ¿La variable tiene un valor útil (está vacía)?
    echo "La variable se considera vacía\n\n";
} else {
    echo "La variable contiene el valor: $usuario \n\n";
}
?>
```

**IMPORTANTE**: La diferencia clave es que la función **isset()** devuelve el booleano _true_ incluso si la variable
contiene un string vacío o un 0, porque representan _existencia_.
Por su lado, la función **empty()** avisa si el valor tiene utilidad práctica para nuestra lógica.

**RECOMENDACIÓN**: Utiliza **isset()** y **empty()** antes de realizar cualquier operación con variables
provenientes de formularios o fuentes externas (como \$\_GET o \$\_POST) para evitar errores. {Véase Sección 10.Solicitudes HTTP para ver su utilidad}
