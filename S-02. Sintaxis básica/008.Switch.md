# 8. ESTRUCTURA DE CONTROL `SWITCH` EN PHP

La **estructura de control `switch`** es una alternativa a la cadena de sentencias `if-elseif-else`. Permite comparar el valor de una misma variable contra múltiples casos explícitos y ejecutar el bloque correspondiente según el resultado de la coincidencia.

---

## 8.1. Sintaxis Básica

```php
<?php
switch ($variable) {
    case $valorA:
        // Código a ejecutar si $variable == $valorA
        break;
    case $valorB:
        // Código a ejecutar si $variable == $valorB
        break;
    case $valorN:
        // Código a ejecutar si $variable == $valorN
        break;
    // Continuar con tantos case como sean necesarios
    default:
        // Código por defecto si ningún case coincide
        break;
}
?>
```

Elementos Clave:

- _case_: Define la condición o valor específico a comparar.
- _break_: Interrumpe la ejecución del bloque **switch**. Si se omite, el intérprete de PHP continuará ejecutando las instrucciones de los casos subsiguientes (fall-through).
- _default_: Bloque opcional que se ejecuta únicamente si el valor evaluado no coincide con ningún _case_ previo.

---

## 8.2. Buenas Prácticas y Tipos de Datos en switch

### 8.2.1. Comparación de Cadenas (string) vs. Enteros (int)

Aunque PHP permite usar cadenas de texto (_string_) dentro de la **estructura de control `switch`**, no suele ser lo más recomendable para lógica estricta:

- Inconveniente con string: Es propenso a errores por variaciones de formato (mayúsculas, minúsculas, espacios adicionales o tildes). Por ejemplo, "Enero" no coincide con "enero" ni con "EnEro ".

```php
<?php
$mesCadena = "EnEro";   // Modifica el formato ("enero", "enerO", "en ero", etc.) y el valor ()

echo "Evaluando la variable \$mesCadena con valor: $mesCadena \n";
echo "Resultado: ";

switch ($mesCadena) {
    case "Enero":
        echo "El mes es enero.\n\n";
        break;
    case "Febrero":
        echo "El mes es febrero.\n\n";
        break;
    default:
        echo "No coincide con ningún 'case'. Probablemente, debido a variaciones de formato (mayúsculas, minúsculas, espacios adicionales o tildes).\n\n";
        break;
}
?>
```

- Uso recomendado con int: Es preferible manejar identificadores numéricos o constantes de tipo entero para evitar fallos de formato y garantizar comparaciones limpias.

### 8.2.2. Agrupamiento de Casos (Case Stacking)

Es posible agrupar múltiples cláusulas case consecutivas para ejecutar una misma acción cuando compartan la misma respuesta o categoría (por ejemplo, agrupar meses para determinar las estaciones del año).

```php
<?php
$mes = 7; // 1 == enero, 2 == febrero, 3 == marzo, y así sucesivamente.

switch ($mes) {
    case 12:
    case 1:
    case 2:
        echo "Es invierno";
        break;
    case 3:
    case 4:
    case 5:
        echo "Es primavera";
        break;
    case 6:
    case 7:
    case 8:
        echo "Es verano";
        break;
    case 9:
    case 10:
    case 11:
        echo "Es otoño";
        break;
    default:
        echo "Mes no válido";
        break;
}
?>
```

## 8.3. "Truco"/patrón Desaconsejado (code smell): La Técnica de _switch (true)_

En la comunidad de desarrollo de software (y particularmente en el ecosistema de PHP), la técnica de _switch (true)_ se considera un truco/patrón desaconsejado (code smell) que roza el **límite de la mala práctica**.

```php
<?php
switch (true) {
    case ($edad >= 0 && $edad < 15):
        echo "Escuincle";
        break;
    case ($edad >= 15 && $edad < 18):
        echo "Adolescente";
        break;
    default:
        echo "Adulto";
        break;
}
?>
```

Aunque es 100% válido desde el punto de vista sintáctico para el intérprete de PHP, no se recomienda su uso en proyectos profesionales por las siguientes razones:

1. Rompe el propósito semántico original de la **estructura de control `switch`** que es evaluar una misma variable u objeto contra múltiples valores discretos/estáticos (por ejemplo: un estado, un día de la semana, un rol de usuario o un código de error).
2. Dificulta la legibilidad y mantenibilidad del código para cualquier programador que lea tu código (o para ti mismo en 6 meses), ver _switch (true)_ resulta confuso porque rompe con la expectativa habitual del patrón de diseño.
3. Es innecesariamente redundante frente a la **estructura de control `if - elseif - else`**. Compara visualmente la estructura anterior con la siguiente para resolver exactamente el mismo problema:

```php
<?php
if ($edad >= 0 && $edad < 15) {
    echo "Escuincle";
} elseif ($edad >= 15 && $edad < 18) {
    echo "Adolescente";
} else {
    echo "Adulto";
}
?>
```

Como verás, la **estructura de control `if - elseif - else`**es más corta, requiere menos palabras reservadas (no requiere escribir _case_ ni _break_ en cada instrucción) y expresa la intencionalidad del código de manera directa.

### 8.3.1. Resumen y Regla de Oro

- Usa la **estructura de control `switch`** (o **`match`** en PHP 8+): Cuando tengas una sola variable y quieras comparar si su valor es exactamente igual a valores fijos/estáticos (case 1:, case 2:, case "ADMIN":).
- Usa la **estructura de control `if - elseif - else`**: Cuando necesites evaluar rangos de números ($edad >= 18), múltiples variables a la vez o condiciones complejas con operadores lógicos (&&, ||).
